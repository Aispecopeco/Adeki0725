# TA VIE｜修正テーマの受け取り

Broadcast 8.1.1のホームを、一つの商品を大きな写真・紹介文・着用風景・細部の写真で伝える構成へ変更しました。冒頭は「家での時間を、あなたらしく。」です。商品ごとの章を縦に重ね、最後に実際の公開記事を表示します。

テーマZIPを開き、GitHubのファイル画面で **Download raw file** を選んでください。「Code → Download ZIP」は説明書を含むリポジトリ全体なので、Shopifyには上記のテーマZIPを使います。元ZIP・説明書・検証用ファイルはテーマZIPへ同梱しません。

連携済みの [ta-vie-shopify-20261005 ブランチ](https://github.com/Aispecopeco/Adeki0725/tree/ta-vie-shopify-20261005) を使用します。「TA VIE｜商品を紹介 → 商品を紹介 → 紹介する商品」で正式商品を選んでください。現在は未選択の2ブロックを用意し、最大6商品まで追加できます。主力商品が決まった後や新商品を登録した後も、商品選択と写真・原稿を差し替えられます。

商品名・価格・詳細ページへのリンクは選択した実商品の情報です。メイン写真は手動選択を優先し、未選択ならその商品の写真を使います。紹介文と着用・細部の写真は確認済みの内容を入力してください。商品未選択時は導入文を残し、設定案内はテーマ編集画面だけに表示します。使えるメイン写真がない場合は主表示を文字・価格・リンクにし、設定した着用・細部写真は表示します。素材・組成・認証や商品の仕様は未確認で、紹介文は空欄です。

元19セクションと旧商品グリッドのID・設定・ブロック・相対順序を保持して非表示にしています。表示設定は商品紹介と読みものの2欄です。記事欄は公開記事があるブログだけを表示し、共通のブログ・FAQリンクとは別に選択します。

サイト全体の「細めのゴシック」、上部リンク・言語・SNS、ホーム末尾ボタンは前回の設定を保持しています。正式SNS URLは未登録です。既存ロゴはヘッダー180／140px、フッター480／240px、メール登録はメール欄のみです。ブログ・FAQの登録・公開と英語の追加・公開はShopify管理画面で別途行います。

実商品・正式写真は未選択で、Shopify上の最終外観・配色警告消失・購入導線は未確認です。テーマ公開や商品・記事・ストア設定の更新は実施していません。[検証の範囲](delivery/validation.md)を確認し、同じ未公開テーマでPC・スマホの表示とリンク先を確認してください。
