# TA VIE｜修正テーマの受け取り

Broadcast 8.1.1 のホームを「写真と短いメッセージ → 商品 → ブランドの考え → 実在する読みもの → 既存のリンクとフッター」の流れに整理しました。元の19セクションのID・ブロック・相対順序と画像参照を残し、繰り返す説明など17セクションを非表示にしています。

テーマZIPを開き、GitHubのファイル画面で **Download raw file** を選んでください。「Code → Download ZIP」は説明書を含むリポジトリ全体なので、Shopifyには上記のテーマZIPを使います。通常のテーマフォルダ構成で、元ZIP・説明書・検証用ファイルは同梱しません。

Shopifyへ連携済みの [ta-vie-shopify-20261005 ブランチ](https://github.com/Aispecopeco/Adeki0725/tree/ta-vie-shopify-20261005) を使います。ホームの商品欄は標準コレクションセクションでPC2列・スマホ1列、最大4点。コレクション未選択ならストアの全商品を使い、実商品がなければ欄ごと表示しません。正式なTA VIEの商品だけを含むコレクションを選択してください。

読みもの欄は標準ブログセクションで、実在する公開記事を最大3件表示します。「テーマ設定 → TA VIE｜ページへのリンク」で既存ブログを選ぶと、記事欄とPC・ハンバーガー・ホーム末尾のリンクが同じブログを使います。記事がなければ記事欄を表示しません。[選択と表示切替の手順](delivery/navigation.md)を参照してください。

ヒーローは2枚の画像スライド、PC650px・スマホ450px、標準の4秒自動送りと矢印を保持し、「ルームウェアを見る」から `/collections/all` へ進めます。空の副ボタンとブランド文章側の未選択の小画像は非表示にしました。大きい画像欄は原ZIPでも未選択なので、現在は標準SVGプレースホルダーです。正式写真の選択が必要です。既存ロゴ参照2件、購入処理、SEO、保存済みの全体設定・配色は今回変更していません。

参考デモの実画面はネットワークの `CONNECT 403` により未確認です。今回の実施確認は [validation.md](delivery/validation.md) に記録します。過去の本文画像を現在版のプレビューとしては使用していません。Shopifyの未公開テーマで実商品・記事・写真・メニュー・購入導線を確認してから公開を判断してください。テーマ公開、商品・記事・ストア設定の更新は実施していません。
