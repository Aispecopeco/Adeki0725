# TA VIE｜修正テーマの受け取り

Broadcast 8.1.1 の標準レイアウトを使い、大きなヒーロー、商品、文中画像、3枚の写真、画像＋文章、マルキー、読みものへ続くホームに整えました。日本語はサイト全体を細めのゴシックに揃え、各セクションの文字サイズ・行間・字間を保持しています。元の19セクションのID・ブロック・相対順序と画像参照を残しています。

テーマZIPを開き、GitHubのファイル画面で **Download raw file** を選んでください。「Code → Download ZIP」は説明書を含むリポジトリ全体なので、Shopifyには上記のテーマZIPを使います。元ZIP・説明書・検証用ファイルはテーマZIPへ同梱しません。

連携済みの [ta-vie-shopify-20261005 ブランチ](https://github.com/Aispecopeco/Adeki0725/tree/ta-vie-shopify-20261005) を使います。設定上はホーム7欄が有効ですが、実商品と公開記事がない通常ストアでは商品・読みもの欄を隠し、5欄を表示します。テーマ編集画面には未選択時の案内を表示します。商品はPC2列・スマホ1列で最大4点、記事は最大3件です。

「TA VIE｜ルームウェア → Collection」で正式な自社コレクションを選びます。読みものはセクションの `Blog` を優先し、未選択なら共通ブログ設定、その次に実在する `news` を使います。共通のブログ・FAQは「テーマ設定 → TA VIE｜ページへのリンク」で選択し、任意URLを入力した場合はリンク先として優先します。記事欄で選んだブログは共通リンクに自動反映しません。上部・PCメニュー・ハンバーガー・ホーム末尾・フッターで行き先を確認してください。

「テーマ設定 → TA VIE｜日本語の文字 → サイト全体の書体」は「細めのゴシック」です。見出しは400、本文・メニュー・ボタン等も既存本文フォントと日本語ゴシックを使用します。「TA VIE｜ホームの文字」は「Broadcastの設定を使う」のままで、追加の行間・字間補正は適用しません。上部リンク・スマホ上部表示・言語・SNSとホーム末尾ボタンはオンですが、SNS URLは未登録です。言語は1つなら実際の言語名、複数なら標準の切替を表示します。ブログ・FAQの作成と公開、英語の追加と公開はShopify管理画面で別途行います。

ヒーローはPC750px・スマホ画面全高、標準の4秒自動送りと矢印を使用。既存ロゴをヘッダー180／140px、フッター480／240pxで見せ、メール登録はメール欄のみです。ホーム写真は原ZIPでも未選択で、現在は標準SVGプレースホルダーです。正式写真の選択が必要です。

公式Theme StoreとBroadcastデモのHTML、公式PC・スマホプレビュー画像は取得・確認しました。対話的なブラウザー確認には証明書の信頼設定の制約が残っています。[検証と制約](delivery/validation.md)を参照してください。Shopify上の最終外観・配色警告消失・購入導線は未確認で、テーマ公開や商品・記事・ストア設定の更新は実施していません。
