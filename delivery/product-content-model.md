# TA VIE｜商品ごとの内容の管理

2026年10月10日の改修用です。テーマは共通レイアウト、文章・写真・動画・寸法は商品ごとのメタオブジェクトへ分けます。管理画面への定義作成、商品の登録・割り当てはまだ実行していません。

## 共通のレイアウトと、商品だけの内容

| 編集する内容 | 編集場所 | 影響する範囲 |
| --- | --- | --- |
| 商品名・価格・色・サイズ・在庫・商品ギャラリー | Shopifyの「商品」 | 編集した商品とそのバリエーション |
| 短いコピー、作った理由、素材、細部、生活場面、寸法、手入れ | 商品専用のメタオブジェクト。商品メタフィールド `ta_vie.feature` で関連付け | 所有商品が一致する、その商品だけ |
| 章の順序・有効／無効、共通見出し、余白・配色など | テーマエディタの「TA VIE 商品特集」 | 同じ商品テンプレートを使う全商品 |
| ホームから紹介する商品・写真・原稿 | テーマエディタのホーム | ホームの紹介のみ。商品のメタオブジェクトを書き換えない |

同じ商品テンプレートで4着を運用しても、商品Aの特集本文を編集して商品Bの本文へ反映される構造ではありません。章の順序や共通の見出しは共有されます。商品ごとに章の順序も変えたい場合は、テーマエディタで商品テンプレートを複製し、該当商品へ割り当ててください。商品の事実を共通セクション設定へ入力しません。

## 初回だけ：定義を用意する

[型定義JSON](ta-vie-metaobject-definitions.json) はレビュー用です。実ストアのIDや認証情報を含まず、自動実行も行いません。管理画面のラベルは更新で変わるため、「カスタムデータ」「メタオブジェクト」「商品メタフィールド」を目印にしてください。

1. 「設定 → カスタムデータ → メタオブジェクト」（または「コンテンツ → メタオブジェクト → 定義を管理」）を開き、同じ型が既に存在するか確認します。存在する定義を削除・再作成せず、フィールドの型と公開設定を比較します。
2. 子の定義 `ta_vie_product_detail`、`ta_vie_product_scene`、`ta_vie_product_size` を先に作成します。下表のキーと型をそのまま使い、「この内容の商品」は商品参照で必須、`label` は1行テキストで必須です。
3. 親の定義 `ta_vie_product_feature` を作成します。`details`、`scenes`、`size_rows` は、対応する子の型だけを選べるメタオブジェクト参照のリストにします。画像欄は画像ファイルだけ、動画欄は動画ファイルだけを許可します。
4. 全4定義でストアフロントからの読み取りを有効にします。公開状態を管理する機能を有効にした場合、掲載するエントリーは「アクティブ」にします。アクティブ化はテーマや商品の公開とは別です。
5. 「設定 → カスタムデータ → 商品 → 定義を追加」で、名前を「TA VIE｜商品特集」、名前空間とキーを **`ta_vie.feature`** にします。型は **メタオブジェクト参照（1件）**、参照先は `ta_vie_product_feature`、ストアフロント読み取りは有効にします。テキスト欄や参照リストにはしません。

定義JSONにはAdmin GraphQL用の読み取りクエリ、定義作成mutation、variablesもあります。APIで適用する場合は、既存定義を確認し、子定義の戻り値IDを親定義の `REPLACE_WITH_GID_...` へ置換します。親定義のIDは商品メタフィールドの参照制約へ入れます。メタデータを含むJSON全体をAPIへ送らず、選んだoperationとvariablesだけを使用してください。ページネーション、APIの`userErrors`、権限と対応バージョンを確認します。このJSONの存在は、管理画面での作成成功を意味しません。

## 定義のフィールド

全4型に共通する `owner_product` は必須の **商品参照** です。実際に紹介する商品を選びます。

### 親：`ta_vie_product_feature`（商品特集）

| キー | 管理画面での意味 | 型 |
| --- | --- | --- |
| `lead` | 一着の短いコピー | 1行テキスト |
| `reason_heading` / `reason_body` | 作った理由の見出し／本文 | 1行テキスト／リッチテキスト |
| `reason_image` / `reason_mobile_image` | 作った理由の写真／スマホ用写真 | ファイル参照・画像 |
| `material_heading` / `material_body` | 素材の見出し／説明 | 1行テキスト／リッチテキスト |
| `material_image` / `material_mobile_image` | 生地の接写／スマホ用写真 | ファイル参照・画像 |
| `material_video` | 生地や着用の短い実写動画 | ファイル参照・動画 |
| `details` | 紹介する細部の順序 | `ta_vie_product_detail` の参照リスト、最大6件 |
| `scenes` | 着て過ごす場面の順序 | `ta_vie_product_scene` の参照リスト、最大3件 |
| `fit_body` | サイズ・着用感、モデル情報、測定方法 | リッチテキスト |
| `size_rows` | 寸法表の行の順序 | `ta_vie_product_size` の参照リスト、最大12件 |
| `care_body` | 確認済みのお手入れ | リッチテキスト |
| `making_body` | 製造・背景の確認済み情報 | リッチテキスト |

### 子：`ta_vie_product_detail`（細部）と `ta_vie_product_scene`（生活場面）

| キー | 管理画面での意味 | 型 |
| --- | --- | --- |
| `label` | 写真を切り替えるボタン名 | 必須の1行テキスト |
| `heading` / `body` | その部位／場面の見出しと説明 | 1行テキスト／リッチテキスト |
| `image` / `mobile_image` | 写真／スマホ用写真 | ファイル参照・画像 |
| `video` | 生活場面の短い実写動画。細部の型にはない | ファイル参照・動画 |

### 子：`ta_vie_product_size`（寸法表の行）

| キー | 管理画面での意味 | 型 |
| --- | --- | --- |
| `label` | 正式なサイズ名 | 必須の1行テキスト |
| `length` / `chest` / `sleeve` | 着丈／身幅／袖丈 | 1行テキスト |
| `waist` / `inseam` | ウエスト／股下 | 1行テキスト |

寸法は確定値と単位を入力します。`chest` は身幅として表示するため、胸囲と混同しません。ウエストも平置き幅か周囲長かを `fit_body` に説明します。型を数値に変えたり、空欄を0で埋めたりしません。対象外・未確認の項目は空欄にし、寸法がない行は表示しません。

## 一着を登録する手順

1. 「コンテンツ → メタオブジェクト」で、この商品の細部・生活場面・寸法の各エントリーを作成します。各 `owner_product` には同じ正式商品を選びます。名前／ハンドルも商品が区別できるものにします。
2. `ta_vie_product_feature` のエントリーを **一商品につき1件** 作ります。`owner_product` にその商品を選び、実物写真と確認済みの原稿を登録します。
3. 親の `details`、`scenes`、`size_rows` に、その商品の子だけを表示順に選びます。子の内容を別商品へ流用する場合も、専用のエントリーを作り、所有商品を別々に設定します。
4. 公開状態を管理する場合、親と子をアクティブにします。画像・動画が未設定でも、確認済み本文だけから始められます。
5. 商品編集画面の「メタフィールド → TA VIE｜商品特集」に、その親エントリーを1件選んで保存します。
6. 未公開テーマのプレビューまたはテーマエディタで、その商品を開きます。既定の商品テンプレートにも新しい特集欄があるため、最初の確認に商品テンプレートの変更は必須ではありません。
7. 専用テンプレートを使う場合、商品編集の「テーマテンプレート」に `ta-vie` が表示される環境で選びます。管理画面の候補は公開テーマのテンプレート構成に左右されるため、未公開テーマにファイルがあるだけで選べるとは限りません。まず未公開テーマのエディタで確認してください。

**別商品への誤表示を防ぐ条件：** 親の `owner_product.value.id` が現在の商品IDと一致したときだけ特集を表示します。子もそれぞれ同じ条件で確認します。不一致の親または子は公開画面へ出さず、編集画面だけに設定案内を出します。共有エントリーの所有商品を付け替えて再利用すると、元の商品では内容が隠れるため、商品の数だけ専用エントリーを作ってください。

## 保存後の確認

商品Aと商品Bを別々に開き、写真・文章が混ざらないことを確認します。商品Aの本文を変更して、商品Bの本文が変わらないことも確認してください。順序を変える場合は、親の参照リスト内の順序と、共通テンプレートの章順序を区別します。所有商品が不一致・未設定、エントリーが下書き、ストアフロント読み取りが無効の場合は、内容が公開画面へ出ないことがあります。

商品名・価格・バリエーション・在庫は従来のBroadcast商品フォームに接続した商品データから表示し、特集用メタオブジェクトには重複保存しません。色・サイズを選ぶ購入機能を、特集本文へ手作業で追加しないでください。
