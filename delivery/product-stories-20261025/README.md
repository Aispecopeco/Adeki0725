# 一着ずつ、写真と説明を見られるホーム

## 今回の変更

- **商品一覧**：`sections/section-collection.liquid` を元のBroadcast（165c385）と完全一致する状態に復元。元のカード・価格・売り切れ表示・クイック購入と、標準スライダーを使います。
- **一着ずつの特集**：写真付きのナビで3組の紹介を切り替えます。各特集には大きな写真、短い説明、特徴を伝える文章を設定済みです。
- **写真**：トップス／パンツ／細部を選択でき、矢印・キーボード・スマートフォンのスワイプでも移動します。写真を押すと拡大でき、閉じると見ていた写真へ操作を戻します。自動再生はしません。
- **動き**：選択はすぐ表示し、特集の文章や写真は穏やかに切り替えます。動きを減らす設定では切り替えのアニメーションを止めます。

[操作プレビュー](interactive-preview.html) ／ [最新テーマZIP](../TA-VIE-Broadcast-product-stories-20261025.zip)

提供された3組の写真の特徴から説明文を作成しました。広い襟ぐりと重なる裾、フードと濃色ボタン、開いた襟と大きなポケットなど、確認できる形状を説明しています。素材混率・原産国・機能などは推測していません。細部用写真のない箇所は同じ写真を拡大し、その旨を表示します。

## テーマエディターで更新する

「オンラインストア → テーマ → カスタマイズ → ホーム」を開きます。

1. **TA VIE｜一着ずつの特集**：見出し、導入文、余白と配色を変更できます。
2. 各 **一着の特集** ブロック：写真ナビの名前、紹介見出し、短い説明、特徴の見出しと本文を編集します。ブロックを並び替えるとナビと特集の順番が一緒に変わります。
3. **用意した写真セット**：既存の3組から選択できます。メイン・2枚目・細部の画像を登録すると、その画像を優先します。写真ボタンの名前と説明も各商品で独立しています。
4. **対応するShopify商品**：現物の写真に対応する商品A〜Dを確認して選択すると、その実商品への「商品詳細を見る」を表示します。選択前は元の商品一覧へ案内します。商品の順番だけで写真をSKUへ割り当てません。
5. **Featured collection**：元のBroadcastの設定です。`Collection` は全商品を選択済みです。表示数やコレクション、標準のGrid／Slider、見出し・ボタンを変更できます。

4着目の写真が用意できたら、特集ブロックを追加して写真と文章を登録してください。共通レイアウトは4着まで対応し、画像未設定の空ブロックを公開画面へ出しません。商品A〜Dの実際の商品情報を表示するには、販売チャネル「オンラインストア」で公開されている必要があります。

ブログ・Instagram／ライブの運用は[既存手順](../journal-20261012/setup-guide.md)のままです。

## ファイル

- `snippets/ta-vie-story-photo.liquid`：写真・説明・細部の拡大表示。
- `assets/ta-vie-product-stories.css`：特集内だけの文字組み・余白・動き。
- `assets/ta-vie-product-stories.js`：商品と写真の切り替え、拡大、キーボード、編集画面の再読み込み対応。
- `sections/section-collection.liquid`：元のコードへ復元。特集の操作は混在させていません。
- `templates/index.json`：特集・元の商品一覧の配置と説明文の初期設定。

旧写真紹介のsnippetとCSSは撤去し、画像5枚は引き続き使っています。元の23セクションを保持し、独立した特集を追加して24セクションです。商品詳細・カート、ブログ・記事、Journal・SNS、設定・配色のコードは置き換えていません。

## プレビューと確認の範囲

商品A〜Dの呼称はご指定の名前です。プレビューの価格・在庫・商品URL・カタログ写真・記事はローカル検証用で、実ストアの情報ではありません。特集の写真と保存済みホーム写真は実際にテーマが使う画像です。

Shopify管理画面の認証がないため、実データの取得、実際の購入・管理画面保存、Shopify側の同期完了は未確認です。検証記録は `verification`、PC・スマホの表示画像は `previews` に保存します。旧成果物は当時のコミットを対象とした記録です。

最終版でブラウザー44件と単一HTMLのPC・スマホ2件が合格しています。静的チェックは元と同じ4エラー・341警告で、追加指摘はありません。表示画像は16枚保存しました。
