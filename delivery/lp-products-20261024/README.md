# ホームLPの商品表示を元のBroadcastで復旧

Shopify管理画面から保存された最新 `165c385` を引き継いで修正しました。保存済みのホーム画像 `shopify://shop_images/tavie-home.png` と最新保存の2枚、既存の日本語、ブログ・Journal・Instagram／ライブ、商品詳細・カートのコードは保持しています。

## 変更した動作

- 元の `Featured product` を有効化し、ホームの最初の画像の次へ移動。商品を選んだ場合はその商品、未選択なら公開済みの通常商品を表示します。
- 元の `Featured collection` をLP上部へ追加。未選択なら全公開商品を読み、元の商品カードで商品名・画像・価格／売り切れ・詳細リンクを表示します。
- 先ほど作成した3商品の写真5枚を、実際のテーマ `assets` に組み込みました。商品データの有無にかかわらず3商品の写真を大きく見られ、上下の写真はタップ・キーボードで開けます。
- 冒頭の既存「ルームウェアを見る」ボタンを有効化し、この商品欄へ移動するようにしました。
- 画像がない実商品は大きな空の紹介を出さず、元の商品一覧に実際の名前・価格／売り切れ・商品URLを残します。

画像を作成しただけの状態から、LP上に写真が出るコードと初期配置まで組み込みました。未登録の `shopify://shop_images/...` を作らず、テーマへ入れたPNGの実在するURLを使っています。

写真とShopifyの商品は別に扱います。商品の並び順だけで写真を別のSKUへ割り当てたり、架空の価格・在庫・購入ボタンを出したりしません。購入の入口は、登録済みの実商品を使う元のカードです。

## 管理画面で編集する場所

「オンラインストア → テーマ → カスタマイズ → ホーム」を開きます。

1. **Featured product**：`Product` で主役の商品を選択。未選択時の自動表示も設定できます。画像がない場合は、先に商品のメディアへ実画像を登録してください。
2. **Featured collection**：`Collection` で掲載するコレクションを選択。未選択時は全商品を参照します。「3商品の写真を独立表示」を無効にすると、写真紹介を隠して実商品の元カードだけを使えます。
3. **商品管理**：既存の「商品A〜D」を開き、販売チャネル「オンラインストア」で公開されていることを確認。名称・価格・在庫・商品メディアの登録内容を、LPの実商品カードへ反映します。

手動で選んだ空のコレクションを、別のコレクションへ勝手に置き換えません。売り切れ商品も除外せず、元の売り切れ表示で見せます。下書き・公開前の商品を公開向けの主役にしません。

ブログ／Instagramの共通設定と更新方法は[既存の運用手順](../journal-20261012/setup-guide.md)のままです。

## 主なファイル

- `sections/section-product.liquid`：元の大きな商品表示。実商品選択／自動選択、未選択や画像なしの公開表示を整理。
- `sections/section-collection.liquid`：元の商品一覧と実際の商品カードを再利用。
- `snippets/ta-vie-product-reference-cards.liquid`：3商品の写真と上下の開閉表示。
- `assets/ta-vie-product-references.css` と `assets/ta-vie-reference-*.png`：対象を限定した見た目と実際の写真。
- `templates/index.json`：LP上部への配置と既存ボタンの接続。

既存22セクションは残し、追加後は23セクションです。元の商品詳細、バリエーション・カート、ブログ・記事、配色設定を置き換えていません。新しいJavaScriptは追加していません。
