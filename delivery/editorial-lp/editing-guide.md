# TA VIE｜編集する場所

## ホームに実際の商品を設定する

1. 未公開の確認用テーマで「カスタマイズ」を開き、「ホームページ」を選びます。
2. 「TA VIE｜一着ずつ紹介」を開きます。初期設定では `all` コレクションの公開商品を自動表示します。「自動表示する商品のコレクション」を選び直すか、「商品未選択の枠はコレクションから表示」をオフにできます。正式な4着と順番を決める場合は、4つの「一着の紹介」ブロックで「この章で紹介する商品」をそれぞれ選択します。明示選択した商品を優先し、自動選択はすでに紹介する商品との重複を除きます。
3. 明示選択した商品ごとに見出し、短い紹介、本文、写真・動画を必要に応じて設定します。見出し・画像・価格の基本情報には選択商品の実データを利用します。正式な文章や写真を上書き設定する場合は、選択商品と一致する内容を登録してください。自動選択した商品にはブロックの上書き文章・写真を使用せず、その商品の実データだけを利用します。
4. PC用とスマートフォン用の写真を使い分ける場合は、「大きく見せる商品写真」「スマートフォン専用の商品写真」に実物写真を登録し、両方の画面幅で切り取りを確認します。「切り替えて見るもう1枚の写真」とボタン名も設定できます。未設定なら同じ商品の次の実画像を利用し、別画像がない場合は写真切替を出しません。動画は生地の動きや着用時のシルエットを伝える短い実写を使い、自動再生せず購入者が再生します。
5. ブロックをドラッグして掲載順を変更します。自動表示が有効な場合は対象コレクション内の並び順も確認してください。自動表示をオフにした未選択ブロックは公開画面へ出しません。候補商品がない場合も仮の商品を表示しません。
6. ブランドの見出し・導入文、開閉して読めるフランス語原文、最初の写真・動画、配色、余白も同じセクションで調整します。最初の写真が未設定なら、先頭で紹介する商品の実画像を利用します。写真の表示は「全体を見せる」か「枠いっぱいに見せる」を選べます。原文を変更するときは、日本語の文章との意味の関係も確認してください。

ホームの各ブロックは独立しています。あるブロックの写真や文章を編集しても、ほかのブロックの商品情報を書き換えません。ただし、ホームはストアで共通の1ページです。商品詳細へ同じ文章を自動保存する機能ではありません。

## 商品詳細の最初の情報

商品名、通常価格・比較価格、商品ギャラリー、色・サイズ、在庫、商品説明はShopify管理画面の「商品」で編集します。購入部分はBroadcastの標準フォームを使います。価格・在庫をLP本文や特集本文へ手入力で重複させないでください。

商品管理画面の説明文がある場合、商品特集の「商品説明」章に表示します。商品の2枚目の実画像があれば、その説明と組み合わせます。説明文がない場合は空の章を出しません。メタオブジェクトをまだ作成していなくても、この説明を利用できます。

通常の説明アコーディオンは、実際に特集側の説明章が表示できた場合だけJavaScriptで重複を抑えます。特集セクションの削除・再読み込み時には元の説明を戻し、JavaScriptが動かない場合も説明を読める構成です。

## 商品ごとの詳しい章を追加する

詳しい内容は、商品メタフィールド **`ta_vie.feature`** が参照する商品専用メタオブジェクトへ登録します。定義が未作成の場合は [既存の定義・登録手順](../product-content-model.md) を使用してください。テーマファイルの追加だけでは管理画面の定義は作成されません。

| 内容 | 編集場所 |
| --- | --- |
| 短いコピー、作った理由、素材の文章・写真・動画 | 親 `ta_vie_product_feature` |
| 襟、袖口、ポケットなどの写真と説明、表示順 | 親の `details` に商品専用の `ta_vie_product_detail` を登録 |
| 朝・午後・夜などの実写写真／動画と説明 | 親の `scenes` に商品専用の `ta_vie_product_scene` を登録 |
| 実寸表、モデル情報、着用感 | 親の `fit_body`、`size_rows` と商品専用の `ta_vie_product_size` |
| お手入れ、確認済みの原産国・製造背景 | 親の `care_body`、`making_body` |
| 章の並び順、共通見出し、写真比率、追従、配色 | テーマエディタの商品テンプレート →「TA VIE 商品特集」 |

親と子の「この内容の商品」には、表示する正式商品を選択してください。その商品IDと一致する内容だけを表示します。一商品につき専用の親・子を作り、他商品のエントリーを付け替えて使い回さないでください。未設定の章やほかの商品に属する情報は通常の画面へ表示しません。

章の順序・共通見出しは同じテンプレートを使う全商品に共通です。商品ごとに章の順序を変えたい場合は、商品テンプレートを複製して割り当てます。商品の本文・写真はテンプレートの共通設定ではなく、商品専用の内容で管理します。

## ブログ・FAQ・言語・SNS

- 「テーマ設定 → TA VIE｜ページへのリンク」で実際のブログとFAQページを選択します。任意URLを使う場合は保存後にリンク先を開いて確認します。既存メニューに同じ行き先がある場合は重複追加を抑えます。
- ヘッダーのメインメニューは `main-menu` を使用します。Shopify管理画面のメニューで正式な項目を登録・編集してください。
- FAQテンプレートは、管理画面の既存FAQページのタイトルと本文を表示します。以前の英語デモの送料・返品条件、仮メールアドレス、セキュリティの文言は無効化しています。ページ本文そのものはShopify管理画面で編集します。ページが存在しない場合は管理画面で作成・公開し、リンク先に選択してください。
- InstagramなどのブランドURLは「テーマ設定」のSNS欄へ登録します。実際のInstagram URLは未設定です。表示をオンにするだけではURLは作成されません。
- 上部の言語表示はストアで公開済みの言語を利用します。英語を追加する場合はShopifyの言語・翻訳・Markets設定で公開先も設定します。
- フッターメニューはテーマエディタの各リンクリストで選択します。ロゴの最大幅はフッターのLogoセクションで調整できます。

## 保存後の確認

商品AとBを別々に開き、写真・説明が混ざらないことを確認してください。PC・スマートフォンの両方で、画像の切り取り、写真切替、章目次、色・サイズ選択、売り切れ表示、カート追加、購入へ戻る導線を確認します。実ストアでの確認前に、ローカルの確認画像だけを公開判断の根拠にはしないでください。
