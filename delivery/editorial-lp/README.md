# TA VIE｜商品を主役にしたLPと商品詳細

2026年10月10日。確認用ブランチは `ta-vie-editorial-lp-20261010` です。Shopify連携済みの `ta-vie-shopify-20261005` への反映・本番公開は行っていません。

今回添付されたBroadcast 8.1.1のテーマを基準に戻し、購入機能、ヘッダー、ハンバーガー、カート、言語・SNSの標準機能を生かしたまま、商品を一着ずつ大きく紹介するホームと、章を読み進める商品詳細へ整えました。

## デザインと商品体験

ホームは商品の写真を大きく見せ、商品名・実際の価格・短い紹介・商品詳細へのリンクを一着ごとにまとめます。4つの商品紹介ブロックは独立して編集できます。横並びの商品一覧だけに頼らず、写真の余白と文章の量を調整して、それぞれの服に目を向けられる構成です。

ブランドの基調は白・グレー・黒、読みやすい日本語、控えめな動きです。ご指定のフランス語は原文を掲載し、日本語では「慣れ親しんだ服の心地よさと、これから長く寄り添う一着への期待」という考え方を伝えます。素材・機能などの商品事実とは分けています。

商品詳細はBroadcastの画像・色・サイズ・価格・在庫・購入フォームを維持します。その下に実際の商品説明を掲載し、商品専用の内容を設定した場合は、作った理由、素材、細部の写真切替、生活場面、実寸、着用感、お手入れ、製造背景へ展開できます。番号付きの目次と購入情報へ戻る導線を設けています。

## 受け取りと確認

テーマの確認用ZIPは [TA-VIE-Broadcast-editorial-LP-20261010.zip](../TA-VIE-Broadcast-editorial-LP-20261010.zip) です。Shopify管理画面のテーマライブラリへ追加して、未公開テーマとして確認してください。ZIPを追加しただけでは、商品・ブログ・FAQの管理データは新規作成されません。

この添付テーマには商品データや実物写真の本体が含まれておらず、ホームの商品も未選択でした。初期設定では実在する `all` コレクションの公開商品から、明示選択した商品との重複を除いて紹介します。正式な4着と順番が決まったら各ブロックで商品を選択してください。自動表示の対象コレクションを変える、または自動表示をオフにすることもできます。公開商品がない場合は、写真の仮枠を出さずブランドの文字を中心に表示します。仮の服、架空の素材情報、3D試作を実物写真として補う処理はありません。

PC・スマートフォンの確認画像を12枚用意しました。[ホームPC](previews/home-desktop-local-fixture.png)・[ホームスマートフォン](previews/home-mobile-local-fixture.png)、[商品詳細PC](previews/product-desktop-local-fixture.png)・[商品詳細スマートフォン](previews/product-mobile-local-fixture.png)、[細部の切替PC](previews/details-desktop-local-fixture.png)・[細部の切替スマートフォン](previews/details-mobile-local-fixture.png)を確認できます。[画像一覧](previews/)には全体表示、商品章、商品なし・写真なしの表示も含みます。商品・価格・写真・ロゴは明示したローカル検証用データで、実ストアの表示や実物写真ではありません。

[検証範囲と未確認項目](verification/README.md)に詳細を記録しています。ローカルでホーム21ケース、商品詳細・購入の主要2ケースと追加12ケースに合格しました。色・サイズ・価格・在庫の連動、カート追加リクエスト、商品固有の内容、キーボード操作、JavaScript無効時などを確認しています。スマートフォンの写真表示順と目次位置の最終調整後は、追加の7ケースを確認しました。Shopify Theme Checkは既存の4エラー・341警告が残り、今回の新規診断は0件です。CLIの終了コードは1で、全体合格とは区別しています。

実ストアには接続していません。Shopifyの実商品・写真・在庫・カートAPI、テーマエディタの保存、実ブログ・FAQ、翻訳・Markets、決済・配送、実機のタッチ操作、未提供の実動画は未確認です。ストアの未公開テーマで実データを設定してから、公開前に確認してください。
