# TA VIE｜商品を仕上げるために必要な素材

今回のテーマZIPには実際の商品データ、商品写真・動画の本体、ブログ記事・ページ本文、メニューの管理データが含まれていません。ホームの商品選択も空です。初期状態では既存ストアの `all` コレクションの公開商品を利用します。実際の対象商品と順番を確認し、必要ならコレクションまたは各ブロックの明示選択を変更してください。既存ストアに登録済みの素材をまず利用し、足りない部分を以下の順で補ってください。

## 先に必要な内容

| 内容 | 必要な情報・構図 | 用途 |
| --- | --- | --- |
| 紹介する約4着 | 正式な商品名または商品URL、掲載順 | ホームの商品ブロックと商品詳細の接続 |
| 商品の全体写真 | 正面から全体のシルエットが分かる実写。余白を含む縦写真 | LPの主役画像・商品ファーストビュー |
| 商品説明 | 実際に確認できる形、素材、仕様の説明 | 商品管理画面の説明と特集の基本章 |
| ブランドのInstagram | 確認済みの公式URL | 上部・モバイル・フッターのSNS導線 |
| ブログ・FAQ | 既存ブログとページの行き先、正式な本文 | ヘッダー・メニュー・フッターの導線 |

商品写真の代わりに、別の服の生成画像や写真から推定した3D試作を自動使用しません。今回の3D試作は、実物の背面・寸法・素材を保証する商品資料にはなりません。

## 一着の理解を深める追加撮影

| 撮影する内容 | 構図・目的 |
| --- | --- |
| 生地の接写 | 表面の質感・織り・光の当たり方が読める距離。色が変わらない自然な光で撮る |
| 正面・側面・背面の着用 | 同じモデル・サイズ・距離で撮り、肩、身幅、丈、落ち感を比較できるようにする |
| 襟・袖口・ボタン・ポケット・縫い目 | 実際に特徴がある部位を選び、写真と説明を1対1で対応させる |
| 座った姿 | 椅子やソファに自然に座り、胴・袖・裾の形が隠れない位置から撮る |
| 生活場面 | 朝の支度、読書、夜のくつろぎなど、利用できる服と撮影環境に合う場面。服の形を家具や小物で隠さない |
| 短い実写動画 | 腕を動かす、座る、歩く、生地を軽く揺らす。着用時の動きが分かる数秒程度の映像 |
| スマートフォン用写真 | 縦に切り取っても襟・袖・裾が残る構図。必要ならPC用とは別カットを用意する |

写真・動画がない章は公開画面に空の枠として残しません。確認済み本文だけから開始できる章もあります。素材が揃ったところから、商品ごとに追加してください。

## 確認してから記載する商品事実

- 素材の正式名称と混率。オーガニック認証やカシミヤの説明は、その商品に対応する表示・仕様書を確認します。
- 原産国、縫製・製造方法、染色や加工の情報。ブランドの意図と製造上の事実を分けます。
- 色・サイズの正式名称と在庫。これらはShopifyの商品・バリエーション情報へ登録します。
- 着丈、身幅、肩幅、袖丈、パンツのウエスト・股下など、該当する実寸と単位、測定方法。身幅と胸囲、平置きウエスト幅と周囲長を混同しません。
- モデルの身長、着用サイズ、フィットの説明。確認できない数値は空欄にします。
- 洗濯表示・保管方法。繊維一般の手入れを、その商品に確認済みの指示として流用しません。
- 正式な送料、発送時期、返品・交換条件。テーマの旧デモ文章をブランドの規約として使いません。

レビュー、検証済みの機能、着心地の測定結果、保証を作成・補完していません。ブランド表現としての文章を磨く場合も、確認できる事実の範囲を守ってください。
