# TA VIE｜Broadcast 修正テーマの引き継ぎ

納品物は `TA-VIE-Broadcast-8.1.1-edited.zip`、この変更・反映手順、検証結果 `validation.md` です。変更キー・変更前後・差分は `changes.json`、ZIPの確認用ハッシュは `SHA256SUMS.txt` に記録しています。ZIPは通常のShopifyテーマ構成で、元ZIP・バックアップ・この説明書を含めません。

対象は提供された **Broadcast 8.1.1** のエクスポート（ファイル名の日付：2026年10月4日）です。10月4日の日付の元ZIPとそのコピーは同一でした。その後、10月5日に警告が出ている連携テーマから取得されたZIPを確認し、`config/settings_data.json` だけが欠落、他の428ファイルはGitHub最新版と一致することが判明しました。[診断と復元手順](shopify-export-diagnosis.md)を参照してください。テーマ公開、商品・ブログ・ストア設定の更新は実施していません。

### 保留した欄を有効にする順序

1. セクションは非表示のまま、実在する商品・コレクション・ブログ・正式画像を選択します。空欄やジュエリーのデモコレクション `rings`／`necklaces` は選びません。
2. 商品名・価格・写真・販売状態・商品数を管理画面で確認します。4点未満なら実際の点数で掲載し、商品や写真を複製して4点に見せません。商品説明は確認できる情報だけで作成します。
3. ボタンのリンク選択欄から確認済みのコレクション／ブログを選び、リンク先をプレビューで確認してからボタンブロックを表示します。空リンクや `#!` をリンクとして有効化しません。
4. 元の構成を確認しながら必要なセクションだけ表示します。記事がない間はブログ一覧やブログへのボタンを追加・表示しません。
5. 同じストアの未公開テーマでPC・スマホを確認します。今回の作業では公開しません。

元の写真は参照を維持していますが、Shopify上での画像内容と正式商品の対応は未確認です。正式な縦写真を確認できたら `double` などの標準画像選択欄から指定し、PCで画像と文章を左右、スマホで縦に並べる配置を確認してください。元の比率と焦点を尊重し、襟・袖・ポケットが切れない表示を優先します。画像を新たに商品へ紐付けるのは、正式な対応を確認してからです。

### 読みものの原稿

管理画面で読みもの欄を用意する場合の紹介原稿は以下です。ブログや記事は今回作成・公開していません。

> **家での時間を整える、ものと過ごし方。**
>
> 衣服から、空間を彩るものまで。家で過ごす毎日を大切にする視点から、気になる品々と暮らしのヒントを紹介します。

以下は管理画面へ貼り付けられる**未公開の記事原稿**です。ストアのブログに反映済みではありません。特定の商品、効果、外部の紹介先を含めていません。

**記事タイトル：家での時間を、自分のために。**

**本文：**

朝の支度、読書をする午後、一日を終えてくつろぐ夜。家で過ごす時間には、それぞれの小さな風景があります。

TA VIEは、日々の暮らしを大切にするルームウェアを提案します。これからこの読みものでは、衣服から空間を彩るものまで、家での時間を整える品々や過ごし方を紹介していきます。

あなたの毎日に、上質を。家にいる自分を、大切に。

**抜粋：** 家にいる自分の装いと、いつもの過ごし方に目を向ける。TA VIEが大切にする、日々の暮らしについて。

## 最新テーマとの整合性確認

今回のZIPを古い設定のまま本番へ直接上書きしないでください。画像がローカルで表示できなくても、Shopifyの保存済み画像参照を消す必要はありません。

1. 同じストアで、最後に編集した最新テーマを特定し、ZIPをダウンロードします。公開中のテーマと最新の作業用テーマが異なる場合は、どちらが今回の基準か確認します。
2. 最新テーマを複製し、未公開の作業用テーマにします。元のテーマを残します。
3. 最新ZIPと提供元ZIPを比較し、画像・商品・コレクション・ブログ・メニュー参照、ホーム順序、セクションID、ロゴ、カラースキームの変更を確認します。
4. 最新テーマを基準に、本書の変更箇所だけを反映します。`config/settings_data.json`、`templates/index.json`、`sections/group-*.json` を丸ごと置換せず、元構成への復旧、対象の文章・文字サイズ・表示設定・配色選択、配色の既定値修正を取り込みます。現在の設定を `current` オブジェクトへ整理する際は、最新の設定値・画像参照・プリセットを同値で保持し、古い値へ戻しません。ホーム用の文字設定4項目、スニペットとホーム限定の読み込み処理も対象箇所だけ取り込みます。対象箇所に最新の自社設定がある場合は、その内容を優先して個別に調整します。
