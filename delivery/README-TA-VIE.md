## Shopifyで行う選択

連携済みの未公開テーマを開きます。ブランチは **`ta-vie-shopify-20261005`** で、再接続は不要です。

1. 「TA VIE｜商品を紹介 → 商品を紹介 → 紹介する商品」で正式な商品を選びます。商品名・価格・リンクはその登録情報を使用します。新しい商品は登録後に選択でき、ブロックは最大6つまで追加できます。
2. 「商品の紹介文」と「メイン写真」を選択します。手動紹介文が空なら本文を省き、商品説明を使う場合だけ「紹介文が空なら商品説明を使用」をオンにします。素材・組成・認証等は正式資料で確認した内容だけを記入します。
3. 「着用・暮らしの写真」と「細部の写真」、必要な説明を追加します。スマホ用の別写真も選択できます。写真がない任意部分は表示しません。権利と商品の対応、スマホでの切れ方を確認します。
4. 「暮らしの読みもの → Blog」で公開記事のあるブログを選びます。未選択時はチェックオンの場合に共通ブログ、その次にnewsを候補にします。記事欄の選択は共通リンクへ自動共有しません。
5. 共通ブログ・FAQは「テーマ設定 → TA VIE｜ページへのリンク」で選択します。任意URLがある場合は共通リンク先として優先します。上部・PCメニュー・ハンバーガー・ホーム末尾・フッターの行き先を確認します。[設定手順](navigation.md)を参照してください。

実商品と正式写真は未選択です。白・グレー・黒を中心にした表現に合わせて、正式商品の写真と原稿を用意してください。オーガニック素材やカシミヤをすべての商品へ当てはめる記述は入れていません。SNS URL、ブログ・FAQのCMS登録と公開、英語の追加・翻訳・公開はShopify管理画面で別途行います。

## 管理画面へ手動反映する原稿

商品・ブログ・FAQの本文とメニューの管理画面データは今回更新していません。以下は必要な場合に手動で使う原稿です。

### 商品説明

商品へのアクセスがなく、正式名称・素材・産地・製造工程・仕様・価格・サイズ等を確認できていません。各商品の説明文は**現登録のまま保留**しています。「商品管理 → 対象の商品」で正式資料と登録内容を照合し、確認できる特徴だけを追記してください。参考写真の見た目から素材・機能・セット内容・対象性別を補うことはできません。

新商品紹介欄の見出しは「家での時間を、あなたらしく。」です。個別の商品名・価格は各ブロックで選択した実商品の登録情報を使い、紹介文は確認済みの原稿を手動で入力します。オーガニック素材・カシミヤの組成や認証等は商品ごとの資料確認後に記載してください。今回、商品登録の内容は変更していません。

### 読みものの原稿

管理画面で読みもの欄を用意する場合の紹介原稿は以下です。ブログや記事は今回作成・公開していません。

> **家での時間を整える、ものと過ごし方。**
>
> 衣服から、空間を彩るものまで。家で過ごす毎日を大切にする視点から、気になる品々と暮らしのヒントを紹介します。

以下は管理画面へ貼り付けられる**未公開の記事原稿**です。ストアのブログに反映済みではありません。特定の商品、効果、外部の紹介先を含めていません。

**記事タイトル：家での時間を、自分のために。**

**本文：**

朝の支度、読書をする午後、一日を終えてくつろぐ夜。家で過ごす時間には、それぞれの小さな風景があります。

外へ出る日の服を選ぶように、家にいる自分の装いにも目を向ける。今日の気分で服を選び、読みたい本を手元に置き、いつもの場所でひと息つく。自分のための時間は、身近なところから始まります。

TA VIEは、日々の暮らしを大切にするルームウェアを提案します。これからこの読みものでは、衣服から空間を彩るものまで、家での時間を整える品々や過ごし方を紹介していきます。

あなたの毎日に、上質を。家にいる自分を、大切に。

**抜粋：** 家にいる自分の装いと、いつもの過ごし方に目を向ける。TA VIEが大切にする、日々の暮らしについて。

「コンテンツ／オンラインストア → ブログ記事」で既存のブランド用ブログを確認します。記事を新規作成する場合は上記のタイトル・本文・抜粋を貼り、既存記事へ反映する場合は対象を確認して元本文を保存してから編集します。ブランド用ブログが存在しなければブログを作成し、記事を所属させます。記事の公開設定は「非公開」のまま保存してください。画像は権利と内容を確認した正式画像だけを選びます。記事の公開は今回の作業範囲に含めません。

記事を閲覧できる状態にした段階で、ホームの読みものセクションのBlogを選びます。メニュー・フッターも同じ行き先にする場合は「テーマ設定 → TA VIE｜ページへのリンク」の共通ブログにも同じブログを指定します。他社商品を紹介する記事には、実際の販売先と権利を確認してから外部リンクを設定します。

### ナビゲーションとFAQ

記事欄はセクションのBlog選択を優先し、上部・メニュー・ホーム末尾・フッターのリンクは共通設定と任意URLを使います。同じブログへ揃える場合はその既存ブログを両方で選択し、任意URLが別の行き先になっていないか確認してください。既存メニューは「コンテンツ → メニュー」で管理します。FAQのデモ送料・返品条件をブランドの事実として書き換えていません。

## 最新設定との整合性

元のID・ブロック・相対順序と参照を保持しています。別の最新テーマへ移す場合は、最新テーマを複製して未公開の作業用テーマにします。設定ファイル、ホームJSON、セクショングループを丸ごと古いZIPで上書きせず、今回の対象箇所だけを取り込みます。最新の画像・商品・ブログ・メニュー参照と現在設定、全5プリセットの配色ID集合を保持してください。
