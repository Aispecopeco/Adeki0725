# TA VIE｜Broadcast 修正テーマの引き継ぎ

対象は提供されたBroadcast 8.1.1です。現在のホームは「写真と短いメッセージ → 商品 → ブランドの考え → 実在する読みもの → 既存のブログ・FAQリンクとフッター」に整理しています。[構成と編集手順](home-structure.md)、[検証結果](validation.md)を参照してください。

納品テーマは `TA-VIE-Broadcast-8.1.1-edited.zip`、431ファイルです。元テーマとの差分は81ファイルで、今回のホーム整理では下表の6ファイルを変更しています。通常のテーマフォルダ構成で、元ZIP・説明書・バックアップ・検証用ファイルを同梱しません。検証結果は [validation.md](validation.md)、変更前後は `changes.json`、ZIPのハッシュは `SHA256SUMS.txt` に記録しています。

## 今回の変更

| ファイル | 変更目的 |
| --- | --- |
| `templates/index.json` | 元の19セクションのID・ブロックツリー・相対順序を保持し、17を非表示。標準の商品・ブログセクションを2つ追加して、繰り返す説明を整理。 |

| `sections/section-blog.liquid`、`snippets/blog-posts.liquid` | 既存の共通ブログ選択を使い、公開記事がある場合だけ標準記事カードを最大3件表示。見出し・説明・一覧リンクを編集できる状態にし、デモ記事を表示しない。 |
| `snippets/ta-vie-home-typography.liquid` | 新しい商品欄の見出しと読みもの欄の見出し・記事タイトル・本文を、ホーム限定の文字補正へ追加。商品カードの書体は対象外。 |
| `blocks/_group-buttons.liquid` | ホームで文言とURLが両方あるボタンだけを表示し、ヒーローの空の副ボタンを非表示。ホーム以外の標準動作は保持。 |

ヒーローは画像スライド2枚、PC650px・スマホ450pxです。標準の4秒自動送り・矢印・JavaScriptを保持し、短い本文と「ルームウェアを見る」から `/collections/all` へ案内します。空の副ボタンは表示しません。既存の画像＋テキスト `double` は、左寄せのブランド文章、標準幅、淡いオフホワイト、上下64pxに調整しました。文章側の未選択の小画像ブロック `image_ycnEVH` はIDと設定を残して非表示にし、大きい画像欄は維持しています。

元の画像を交えた文章、暮らしの3場面、2枚の画像＋文章、マルキー、Dynamic grid、画像の列、スクロール画像は設定を残して非表示です。掲載実績・品質・SNS等の裏付けのないデモ欄も引き続き非表示です。新しい写真・ロゴ・動画は作っていません。

保存済みの全体設定・配色と共通の `type_*` 書体は今回変更していません。既存のヘッダー・フッター、ロゴ参照2件、購入フォーム・購入用JavaScript、価格・在庫・バリエーション処理、SEOメタ情報・canonical・商品構造化データは維持しています。ホーム専用の文字補正は標準のアニメーションを置き換えません。

## Shopifyで選択する内容

連携済みの未公開テーマを開き、ホームで以下を設定します。再接続は不要です。連携ブランチは **`ta-vie-shopify-20261005`** です。

1. 「TA VIE｜ルームウェア → Collection」で正式な自社コレクションを選択します。「未選択時に全商品を使用、商品がなければ非表示」はオンです。未選択ならストアの全商品が対象なので、TA VIE以外が含まれないか確認してください。選択先が無効・空なら別のコレクションへ置き換えず非表示にします。
2. 「テーマ設定 → TA VIE｜ページへのリンク → 読みもののブログ」で既存ブログを選択します。「TA VIE｜暮らしの読みもの → TA VIEのブログ設定を使う」はオンです。未選択時だけ、公開記事のある `news` を補助候補にします。実記事がなければ記事欄全体を非表示にします。
3. 同じ設定グループでFAQページを選び、必要なリンク表示をオンにします。ホーム末尾のボタン切替と記事欄の表示は独立しています。[navigation.md](navigation.md)を参照してください。
4. ヒーローと `double` に正式写真を選択し、同じストアの未公開プレビューでPC・スマホの比率・焦点・メニュー・商品リンク・記事リンクを確認します。写真は原ZIPでも未選択で、現在は標準SVGプレースホルダーです。

記事・商品を複製して表示数を埋めたり、名称・仕様・価格を推測したりしていません。新しいグローバル設定グループも追加していません。今回追加した切替は標準の商品・ブログセクション内の設定です。

## 管理画面へ手動反映する原稿

商品・ブログ・FAQの本文とメニューの管理画面データは今回更新していません。以下は必要な場合に手動で使う原稿です。

### 商品説明

商品へのアクセスがなく、正式名称・素材・産地・製造工程・仕様・価格・サイズ等を確認できていません。各商品の説明文は**現登録のまま保留**しています。「商品管理 → 対象の商品」で正式資料と登録内容を照合し、確認できる特徴だけを追記してください。参考写真の見た目から素材・機能・セット内容・対象性別を補うことはできません。

商品紹介を表示する場合の見出し原稿は「日常に寄り添うルームウェア。」です。個別の商品名・価格・写真は、選択した実在するコレクションの登録情報を使ってください。今回、商品登録の内容は変更していません。

### 読みものの原稿

管理画面で読みもの欄を用意する場合の紹介原稿は以下です。ブログや記事は今回作成・公開していません。

> **家での時間を整える、ものと過ごし方。**
>
> 衣服から、空間を彩るものまで。家で過ごす毎日を大切にする視点から、気になる品々と暮らしのヒントを紹介します。

以下は管理画面へ貼り付けられる**未公開の記事原稿**です。ストアのブログに反映済みではありません。特定の商品、効果、外部の紹介先を含めていません。

**記事タイトル：家での時間を、自分のために。**

**本文：**

朝の支度、読書をする午後、一日を終えてくつろぐ夜。家で過ごす時間には、それぞれの小さな風景があります。

外へ出る日の服を選ぶように、家にいる自分の装いにも目を向ける。今日の気分で服を選び、読みたい本を手元に置き、いつもの場所でひと息つく。自分のための時間は、身近なところから始まります。

TA VIEは、日々の暮らしを大切にするルームウェアを提案します。これからこの読みものでは、衣服から空間を彩るものまで、家での時間を整える品々や過ごし方を紹介していきます。

あなたの毎日に、上質を。家にいる自分を、大切に。

**抜粋：** 家にいる自分の装いと、いつもの過ごし方に目を向ける。TA VIEが大切にする、日々の暮らしについて。

「コンテンツ／オンラインストア → ブログ記事」で既存のブランド用ブログを確認します。記事を新規作成する場合は上記のタイトル・本文・抜粋を貼り、既存記事へ反映する場合は対象を確認して元本文を保存してから編集します。ブランド用ブログが存在しなければブログを作成し、記事を所属させます。記事の公開設定は「非公開」のまま保存してください。画像は権利と内容を確認した正式画像だけを選びます。記事の公開は今回の作業範囲に含めません。

記事を閲覧できる状態にした段階で「テーマ設定 → TA VIE｜ページへのリンク」の共通ブログを選びます。現在のホームの標準ブログセクションと一覧リンクが同じ行き先を使います。他社商品を紹介する記事には、実際の販売先と権利を確認してから外部リンクを設定します。

### ナビゲーションとFAQ

ブログ・FAQへの行き先は「テーマ設定 → TA VIE｜ページへのリンク」で選びます。既存メニューに同じURLまたは同じ資源がある場合、メニューへの追加は省きます。メニューの管理画面データ自体は変更していません。必要なら「コンテンツ → メニュー」で既存内容を確認して編集します。

FAQにデモの送料・返品条件がある場合は、正式な条件を確認してから別途修正してください。FAQテンプレートや本文をブランドの事実として書き換えていません。

## 最新設定との整合性

今回の連携テーマには、Shopifyからの設定保存コミット `3f7e253` を確認しています。これは過去の設定ファイルの保存確認であり、今回のホーム変更の実画面や配色警告消失の確認とは別です。[過去の欠落・保存エラーの記録](shopify-export-diagnosis.md)も残しています。

別の最新テーマへ移す場合は、最新テーマを複製して未公開の作業用テーマにします。`settings_data.json`・ホームJSON・セクショングループを丸ごと古いZIPで上書きせず、対象の文章・表示設定・新規2セクション・関連する限定変更だけを取り込みます。最新の画像・商品・ブログ・メニュー参照、元のID・ブロックツリーと相対順序を維持し、全5プリセットと現在設定の配色ID集合も保持してください。

## 確認と不足情報

現在版の検証内容と未確認項目は [validation.md](validation.md) に記録します。過去の9セクション表示版の画像や検証結果を、今回のホームの実画面確認として扱っていません。

参考デモはネットワークの `CONNECT 403` により外観を確認できませんでした。`themes.shopify.com`、`broadcast-theme-main.myshopify.com`、`cdn.shopify.com` のネットワーク設定はクラウド環境のドラフトに追加されています。環境設定を保存・Publishした後に再試行する必要があり、現在の実行環境への適用は未確認です。参考サイトを閲覧済みとはしていません。

不足しているのは正式な商品登録・コレクション、商品名と特徴の資料、正式写真と使用権利・商品の対応、実在する公開記事とFAQ内容です。必要な撮影カットは「服全体の着用」「前後の形」「襟・袖・ポケットの寄り」「家での着用場面」です。参考写真を販売商品へ紐付けるのは、使用可否と対応を確認してからです。

テーマ公開、商品・記事の作成／変更、ストア設定の変更は実施していません。実ストアのPC・スマホ表示、写真、メール登録、カート・購入導線は未確認です。
