# TA VIE｜Broadcast 修正テーマの引き継ぎ

対象は提供されたBroadcast 8.1.1です。公式デモのHTMLと公式PC・スマホプレビュー画像を確認し、標準の大きなヒーロー、文中画像、3列写真、画像＋文章、マルキーを使う構成へ整えました。[編集手順](home-structure.md)と[検証結果](validation.md)を参照してください。

納品は `TA-VIE-Broadcast-8.1.1-edited.zip`、431テーマファイルです。原本との差分は81ファイル、今回の変更は前回版から12ソースファイルです。通常のテーマ構成で、元ZIP・説明書・バックアップ・検証用ファイルを同梱しません。差分は `changes.json`、ZIPのハッシュは `SHA256SUMS.txt` に記録しています。

設定上はホーム7欄が有効ですが、実商品と公開記事がない通常ストアではその2欄を隠して5欄を表示します。未選択の案内はテーマ編集画面だけに表示します。元19セクションのうち5つと標準の追加2つを有効にし、残る元14欄は設定を残して非表示です。

ヒーローはPC750px・スマホ画面全高、画像スライド2枚、標準の4秒自動送りと矢印です。CTAは `/collections/all`。文中画像の導入は32／26px、3枚の写真はPC3列・スマホ標準スライダー、ストーリーは全幅に余白を取る配置と2段落、マルキーは速度設定50です。文字はBroadcast本来の書体・太さ・行間・字間を使用します。

既存ロゴ参照2件と縦横比、購入フォーム・購入用JavaScript、価格・在庫・バリエーション処理、SEOメタ情報・canonical・商品構造化データは維持しています。新しい写真・ロゴ・動画は作っていません。

## Shopifyで行う選択

連携済みの未公開テーマを開きます。連携ブランチは **`ta-vie-shopify-20261005`** で、再接続は不要です。

1. 「TA VIE｜ルームウェア → Collection」で正式な自社コレクションを選びます。未選択ならストアの全商品が対象なので、TA VIE以外が含まれないか確認します。無効・空の選択先は別のコレクションへ置き換えず非表示にします。
2. 「暮らしの読みもの → Blog」で公開記事のあるブログを選びます。未選択なら「未選択時に共通ブログ設定を使う」がオンの場合に共通ブログを使い、どちらも未選択ならnewsを候補にします。選択済みの無効・空ブログは自動で置き換えません。
3. 「テーマ設定 → TA VIE｜ページへのリンク」で共通ブログ・FAQを選びます。フッターは既存メニューを優先し、空の場合の補助を別のチェックで管理します。[リンクとフッターの設定](navigation.md)を参照してください。
4. ヒーロー、文中画像、3枚の写真、ストーリーに正式写真を選択します。原ZIPでも写真は未選択で、現在は標準SVGプレースホルダーです。権利と商品との対応を確認し、同じ未公開テーマのPC・スマホで比率・焦点・メニュー・実商品と記事リンクを確認します。

商品・記事を複製して件数を埋めたり、名称・仕様・価格を推測したりしていません。送料・返品等のFAQ内容は正式情報を確認してから別途編集してください。

## 管理画面へ手動反映する原稿

商品・ブログ・FAQの本文とメニューの管理画面データは今回更新していません。以下は必要な場合に手動で使う原稿です。

### 商品説明

商品へのアクセスがなく、正式名称・素材・産地・製造工程・仕様・価格・サイズ等を確認できていません。各商品の説明文は**現登録のまま保留**しています。「商品管理 → 対象の商品」で正式資料と登録内容を照合し、確認できる特徴だけを追記してください。参考写真の見た目から素材・機能・セット内容・対象性別を補うことはできません。

商品紹介を表示する場合の見出し原稿は「日常に寄り添うルームウェア。」です。個別の商品名・価格・写真は、選択した実在するコレクションの登録情報を使ってください。今回、商品登録の内容は変更していません。

### 読みものの原稿

管理画面で読みもの欄を用意する場合の紹介原稿は以下です。ブログや記事は今回作成・公開していません。

> **家での時間を整える、ものと過ごし方。**
>
> 衣服から、空間を彩るものまで。家で過ごす毎日を大切にする視点から、気になる品々と暮らしのヒントを紹介します。

以下は管理画面へ貼り付けられる**未公開の記事原稿**です。ストアのブログに反映済みではありません。特定の商品、効果、外部の紹介先を含めていません。

**記事タイトル：家での時間を、自分のために。**

**本文：**

朝の支度、読書をする午後、一日を終えてくつろぐ夜。家で過ごす時間には、それぞれの小さな風景があります。

外へ出る日の服を選ぶように、家にいる自分の装いにも目を向ける。今日の気分で服を選び、読みたい本を手元に置き、いつもの場所でひと息つく。自分のための時間は、身近なところから始まります。

TA VIEは、日々の暮らしを大切にするルームウェアを提案します。これからこの読みものでは、衣服から空間を彩るものまで、家での時間を整える品々や過ごし方を紹介していきます。

あなたの毎日に、上質を。家にいる自分を、大切に。

**抜粋：** 家にいる自分の装いと、いつもの過ごし方に目を向ける。TA VIEが大切にする、日々の暮らしについて。

「コンテンツ／オンラインストア → ブログ記事」で既存のブランド用ブログを確認します。記事を新規作成する場合は上記のタイトル・本文・抜粋を貼り、既存記事へ反映する場合は対象を確認して元本文を保存してから編集します。ブランド用ブログが存在しなければブログを作成し、記事を所属させます。記事の公開設定は「非公開」のまま保存してください。画像は権利と内容を確認した正式画像だけを選びます。記事の公開は今回の作業範囲に含めません。

記事を閲覧できる状態にした段階で、ホームの読みものセクションのBlogを選びます。メニュー・フッターも同じ行き先にする場合は「テーマ設定 → TA VIE｜ページへのリンク」の共通ブログにも同じブログを指定します。他社商品を紹介する記事には、実際の販売先と権利を確認してから外部リンクを設定します。

### ナビゲーションとFAQ

記事欄はセクションのBlog選択を優先し、メニュー・フッターの補助リンクは共通のブログ・FAQ設定を使います。同じブログへ揃える場合は、その既存ブログを両方で選択してください。既存メニューは「コンテンツ → メニュー」で管理します。FAQのデモ送料・返品条件をブランドの事実として書き換えていません。

## 最新設定との整合性

元のID・ブロック・相対順序と参照を保持しています。別の最新テーマへ移す場合は、最新テーマを複製して未公開の作業用テーマにします。設定ファイル、ホームJSON、セクショングループを丸ごと古いZIPで上書きせず、今回の対象箇所だけを取り込みます。最新の画像・商品・ブログ・メニュー参照と現在設定、全5プリセットの配色ID集合を保持してください。

Shopifyからの設定保存コミット `3f7e253` は過去に確認しました。今回の改善が実ストアで成功したことや配色警告の消失は、別途確認が必要です。[過去の保存エラーの記録](shopify-export-diagnosis.md)を残しています。

## 参考確認と不足情報

公式Theme StoreページとBroadcastデモのHTML、公式PC・スマホプレビュー画像はTLS検証を有効にして取得・確認しました。デモHTMLは8.1.0、提供テーマは8.1.1で、版が完全一致するとはしていません。リモートブラウザーでのスライド・メニュー操作は証明書の信頼設定の制約により未確認です。[検証と制約](validation.md)を参照してください。

現在版のローカル検証結果も [validation.md](validation.md) に記録します。前回の4欄版・本文画像を現在版のプレビューには使っていません。実ストアのPC・スマホ表示、正式商品・写真・記事、配色警告、メール登録と購入導線は未確認です。

不足しているのは正式な商品登録・コレクション、商品名と特徴の資料、正式写真と使用権利・商品の対応、公開記事とFAQ内容です。必要な撮影カットは「服全体の着用」「前後の形」「襟・袖・ポケットの寄り」「家での着用場面」です。テーマ公開、商品・記事・ストア設定の更新は実施していません。
