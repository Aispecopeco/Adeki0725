# TA VIE｜商品を深く紹介するための素材

2026年10月10日の商品体験改修で使用する素材の準備表です。商品の素材名・混率・仕様・着心地は確認できた資料だけを記載します。「カシミヤ」「オーガニック」の構想を、全商品の確定した仕様として扱いません。撮影前に実商品との対応と使用権利を確認してください。

## 一着ごとに用意する写真・動画

| 用途 | 目的と構図 | 準備の目安 |
| --- | --- | --- |
| ファーストビュー／商品ギャラリー | 正面・横・背面の実着用。頭から足元までを入れ、丈、袖、肩、身幅が分かる距離。白い服が背景に溶け込まない光と背景を使う。 | 共通は縦位置、長辺2,000px程度以上。既存商品の写真を優先。 |
| 作った理由 | 服を着て家で過ごす全景。写真内に文章を焼き込まず、身体・服・空間の関係を見せる。 | 横位置と、同じ場面のスマホ向け縦位置。 |
| 生地の接写 | 実物の織り／編み・光沢・表面が分かる斜めの自然光。質感を確認できる近さ。過度な色補正やぼかしを避ける。 | 1〜2枚。トリミングに耐える解像度。 |
| 襟・袖・留め具など | その商品で説明する部位を1枚ずつ接写。ボタン、パイピング、袖口、縫い目、ウエストなど、実物にある部分を選ぶ。 | 部位名と写真の対応表。存在しない仕様を説明しない。 |
| 立った姿と座った姿 | 立って朝の支度、椅子やソファで読書など。肩・膝・腰周りが見え、丈と落ち方が分かる画角。 | 朝・午後・夜の全場面を埋める必要はない。使える場面から設定。 |
| 動き | 歩く、座る、腕を動かす、裾が揺れるなど。実際の服の動きに焦点を当て、無音でも意味が伝わる。 | 5〜10秒程度の短い実写動画。動画がなければ静止画で構成。 |
| サイズ選び | 商品の平置き、測定する部位、着用比較。モデルが異なる場合は写真ごとに身長と着用サイズを記録。 | 写真と測定方法・単位をセットで用意。 |

横位置だけの場合は、スマホで服が切れないかを確認します。生地接写を全身写真の代替にせず、全身・生活場面・細部に役割を分けます。参考サイトの商品写真、生成した別の服、画像から推測した素材を商品紹介へ補いません。

## 商品ごとに確認する情報

- 正式商品名、実売価格、色・サイズのバリエーション、販売／在庫状態。
- 素材の正式名称と混率。オーガニック、認証、産地、製造工程は裏付け資料があるものだけ。
- 寸法表と単位、測定位置、許容差についてのメーカー／ブランドの確定説明。
- 写真に登場するモデルの身長と着用サイズ。フィットの説明は確認済みのもの。
- 洗濯・乾燥・アイロン・クリーニングなどの確定したお手入れ表示。
- 商品の仕様と開発の理由。機能・着心地の検証結果、レビュー、比較数値は実際の記録がある場合だけ。

文章は「何を目指した服か」というブランドの表現と、「素材・仕様・検証結果」という事実を分けて確認してください。柔らかさ、保温性、通気性なども、写真だけでは確定できません。

## 設定前のチェック

1. 各写真・原稿・動画を正式商品にひも付け、別の商品へ混ざらないよう整理します。
2. 必要な使用権利とモデルへの掲載許諾を確認します。
3. 説明的な代替テキストを付けます。装飾写真は内容との重複を避けます。
4. メタオブジェクトへ登録した後、PCとスマホの切り取り・読みやすさを未公開テーマで確認します。

素材が未設定の章は公開画面に仮の説明や空枠を残さず省く設計です。正式な商品写真・商品情報の登録とShopifyへの公開は、このコードの納品には含まれていません。設定手順は [商品ごとの内容の管理](product-content-model.md) を参照してください。
