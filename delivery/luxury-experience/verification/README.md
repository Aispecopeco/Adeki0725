# TA VIE｜検証範囲と操作プレビュー

2026年10月10日。実ストアの認証には接続せず、現在のテーマLiquid・Broadcast CSS/JavaScriptをローカルのShopify形式データとAPIアダプターで動作確認しました。写真枠、商品名、価格、寸法、商品説明はすべて「LOCAL PREVIEW」と明示した検証用データです。実物と異なる服の画像は使用していません。

## 操作できる成果物

[単体HTMLの操作プレビュー](../interactive-preview.html)は、ホームと4着の商品詳細をひとつのファイルに収めています。写真切替・細部表示・商品移動・サイズと色の選択・検証用カートを操作できます。GitHubのファイル画面はHTMLを実行しないため、Rawのファイルをダウンロードしてブラウザーで開いてください。

[操作プレビューZIP](../../TA-VIE-luxury-interactive-preview-20261010.zip)には、単体HTMLと同じ内容のページ別フォルダーを含めます。このZIPはShopifyテーマへアップロードするファイルではありません。

管理されたChromiumは `file://` の直接表示を `ERR_BLOCKED_BY_ADMINISTRATOR` で禁止していました。この制限は変更せず、許可されたHTTPで単体HTMLを1回読み込み、その後のすべてのネットワーク要求を遮断して1280px・390pxの操作を確認しました。追加のHTTP要求、遮断されたアセット要求、JavaScriptエラーは0件でした。直接の `file://` 表示は、この環境では未確認です。

カートは、そのプレビューページで最後に追加した商品と数量を示す操作デモです。注文・支払い・実在庫更新は行わず、ページを変えるとリセットします。APIアダプター・検証用画像・検証用商品は、本体のShopifyテーマに組み込みません。
