## 見た目と操作

温かみのある白、チャコール、控えめなグレージュを基調に、大きな写真と余白、日本語の見出し・本文・価格の読みやすさをそろえます。鮮やかなデモ色や太い文字帯は、服を主役にする強さへ調整します。

商品の写真と短い説明をタブで切り替え、実際の接写がある場合は「細部を見る」から拡大した写真と説明を開けます。写真内のポイントは商品ごとに編集でき、閉じると元の操作へ戻ります。写真付きの商品ナビは4着の特集を行き来する入口です。スマートフォンでは閲覧中の商品名・価格・詳細とサイズ選択の入口も見つけられるようにしています。色・サイズ・在庫・購入はBroadcastの商品フォームにつなぎ、特集本文へ価格や在庫を複製しません。

写真の切替、細部表示、商品ナビはクリック・タップ・キーボードで使えます。スワイプはボタン操作と併用し、通常の縦スクロールを維持します。動画は実際のファイルを設定した場合だけ表示し、購入者が再生します。JavaScriptが利用できない場合も主な説明とリンクを読める構成です。

## Shopify側に残る設定

1. 正式な4着と紹介順を選び、オンラインストアへの公開状態を確認します。
2. 各商品の実物写真・必要な動画・確認済みの商品説明を登録します。
3. 写真に用途ごとの名前と説明を付ける場合は `ta_vie.views` の定義を作成し、所有商品が一致する項目を商品ごとに設定します。
4. 接写がある項目に細部写真を設定し、ポイントの位置をPCとスマートフォンで確認します。
5. サイズ・色・価格・在庫を商品管理画面で確認し、未公開テーマで購入フォームとカートを確認します。
6. メニュー、実際のブログ・FAQページ、SNS URL、公開する言語を管理画面で設定します。テーマファイルだけでは、これらの管理データは新規作成されません。

元デモの `WELCOME10` や送料無料の案内は、実際の条件が確認できないため初期状態で無効にしています。正式なキャンペーンや送料条件が決まった場合、Shopifyの割引・配送設定と表示原稿をそろえてから有効にしてください。表示を有効にするだけでは割引や配送ルールは作成されません。
