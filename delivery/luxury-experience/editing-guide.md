# TA VIE｜商品ごとの写真と説明を編集する

## 編集場所を分ける

| 編集したい内容 | 編集場所 | 変更が反映される範囲 |
| --- | --- | --- |
| 商品名、価格、色・サイズ、在庫、商品ギャラリー、商品説明 | Shopify管理画面の「商品」 | 選んだ商品とそのバリエーション |
| ホームで紹介する4着・紹介順・共通のブランド文 | テーマエディタのホーム | ストアのホーム |
| 「着用」「シルエット」「生地」などの写真と短い説明、細部の接写とポイント | 商品専用の `ta_vie_product_view`、商品メタフィールド `ta_vie.views` | 所有商品が一致する、その商品だけ |
| 素材・作った理由・生活場面・寸法・お手入れの詳しい章 | 既存の商品メタフィールド `ta_vie.feature` | 所有商品が一致する、その商品だけ |
| 共通の写真比率、見出し、余白、セクションの表示順 | テーマエディタ | 同じテンプレートを使う商品／ホーム |

特集用の文章に価格・在庫・サイズ選択を手入力しません。購入情報はBroadcastの既存フォームで更新します。商品Aの項目を商品Bへ使い回す場合も、別のエントリーを作り、所有商品をそれぞれ設定してください。

## 共通の配色・文字・動き

**「テーマ設定 → TA VIE｜上質な装い」** で、**「TA VIEの配色・文字組みを使う」**、**「見出しの書体」**、**「日本語本文の文字サイズ」**、**「写真とパネルの切り替え時間」** を編集します。初期設定は細めの明朝見出し、読みやすい本文16px、切替280msです。本文は14〜18px、切替は200〜400msの範囲で調整できます。端末の「動きを減らす」を有効にしている場合は、その設定を優先します。

ホームと商品特集の配色は各セクションの「配色」で選びます。共通の温かい白は `scheme-tavie-white`、グレージュは `scheme-tavie-soft` です。配色や本文サイズを変えたら、写真・ロゴとの関係と、文字や操作部品の読みやすさをPCとスマートフォンで確認してください。

## ホームの4着を選ぶ

1. 未公開テーマの「カスタマイズ → ホームページ」で **「TA VIE｜一着を知る」** を開きます。
2. 4つの **「紹介する一着」** ブロックで **「この枠の商品」** をそれぞれ選びます。正式商品を明示的に選び、ブロックを並び替えることで4着と紹介順を確定できます。
3. 初期設定の **「商品が未選択の枠を自動で設定」** がオンの場合、未選択の枠には **「自動選択するコレクション」** の順序で商品を入れます。コレクション未選択なら公開中の全商品を使います。明示選択した全商品と、すでに紹介している商品との重複を除きます。正式な4着だけを表示したい場合は、商品を明示選択してから自動設定をオフにします。
4. 明示選択した商品に限り **「特集用の見出し」**、**「この一着の短いコピー」**、**「この一着の紹介文」** を上書きできます。空欄なら実際の商品名、この商品が所有する特集のコピー・本文、または商品の説明を利用します。自動選択した商品には、以前のブロックの上書き文章を適用しません。選択商品を変更するときは、同じブロックの上書き文章も新しい商品に合わせて見直すか、空欄に戻してください。
5. 写真と切替説明は、選択商品のギャラリーまたは **「TA VIE｜写真の切り替え」** で設定します。ホームのブロックに別商品の写真を共通保存する構造ではありません。
6. **「写真付きの商品ナビを表示」**、**「写真エリアの比率」**、ブランドの見出し・紹介、配色、上下の余白を調整します。商品ナビはホーム内の各特集へ移動し、商品詳細・色とサイズのリンクは正式な商品ページへ進みます。スマートフォンの閲覧中商品・価格・購入入口の表示も、商品ナビの表示設定に連動します。

紹介できる商品がない場合は、ブランドの文章と実際の商品一覧へのリンクを表示し、仮の商品枠を出しません。登録商品が4着未満なら、利用できる商品だけを表示します。ホームの共通原稿は商品の管理データへ自動保存されないため、商品ページにも必要な原稿は商品専用データへ登録してください。

## 最初の表示を確認する

商品に実画像がある場合、写真切替用の新しい定義がなくても、その商品のギャラリーから最大6枚を利用します。短く有効な代替テキストがあれば選択名へ使用し、それ以外は「写真 01」のような名前を表示します。元の商品名だけの代替テキストを、異なる用途名へ作り変えることはありません。

用途ごとの名前・説明・接写・ポイントを追加する場合は、以下の新しい定義を設定します。写真や動画がない商品には空の写真枠を出しません。

## 初回のみ：写真切替用の定義を作る

[data-model.json](data-model.json) はShopify Admin GraphQLのレビュー用データです。APIで実行した記録ではなく、管理画面に定義はまだ作成されていません。

1. Shopifyの「設定 → カスタムデータ」または「コンテンツ → メタオブジェクト」から既存の定義を確認します。`ta_vie_product_view` や商品メタフィールド `ta_vie.views` が存在する場合、削除せずフィールドの型・キー・公開設定を比較します。
2. メタオブジェクト定義を追加し、型を **`ta_vie_product_view`**、名前を **「TA VIE｜商品の写真と細部」** にします。下表のフィールドを同じキーと型で作ります。
3. ストアフロントの読み取りを有効にします。公開状態を管理する機能を有効にした場合、掲載するエントリーを「アクティブ」にします。
4. 商品のメタフィールドを追加し、名前を **「TA VIE｜写真の切り替え」**、名前空間を **`ta_vie`**、キーを **`views`** にします。型は **メタオブジェクト参照のリスト**、参照先は `ta_vie_product_view`、最大8件、ストアフロント読み取りは有効です。

以前の `ta_vie.feature` とその4種類の定義は、この写真切替のために再作成する必要はありません。詳しい章を運用する場合だけ、[既存の管理手順](../product-content-model.md)を使います。

今回の細部操作は `ta_vie.views` の接写を使用します。以前の `ta_vie.feature.details` と `ta_vie_product_detail` のエントリーは削除しませんが、新しい特集では表示に使いません。既に細部の写真・原稿を登録している場合は、対応する商品の新しい写真項目へ接写と説明を移してください。理由・素材・生活場面・寸法・手入れ・製造背景は、従来の特集データを引き続き読み込みます。

| キー | 管理画面の名前 | 型・入力内容 |
| --- | --- | --- |
| `owner_product` | この内容の商品 | 必須の商品参照。実際に表示する商品 |
| `label` | 選択ボタンの名前 | 必須の1行テキスト。写真で確認できる用途だけを入力 |
| `image` | 大きく見せる写真 | ファイル参照、画像のみ |
| `mobile_image` | スマートフォン専用の写真 | ファイル参照、画像のみ。空欄なら共通の写真 |
| `video` | 短い実写動画 | ファイル参照、動画のみ。未設定なら写真だけで成立 |
| `heading` / `body` | 写真の見出し／説明 | 1行テキスト／リッチテキスト |
| `detail_image` | 細部の接写 | ファイル参照、画像のみ |
| `detail_heading` / `detail_body` | 細部の見出し／説明 | 1行テキスト／リッチテキスト |
| `show_hotspot` | 写真内のポイントを表示 | 真偽値。接写がある項目だけ有効 |
| `hotspot_x` / `hotspot_y` | ポイントの横位置／縦位置 | 小数。0〜100%。左上が0、右下が100 |

## 一着の写真を登録する

1. 「コンテンツ → メタオブジェクト」で、この商品の写真項目を作ります。「この内容の商品」には正式な商品を選びます。項目は商品ごとに独立して作ります。
2. 「選択ボタンの名前」に「着用」「背面」「生地」など、実際に見せられる写真に合った短い名前を入力します。写真または動画を設定します。写真・動画が両方ない項目は表示しません。
3. 必要な見出しと説明を入力します。未確認の素材・製法・産地・機能を足さず、画像から分かる形や確認済みの情報を使います。本文だけの仮項目を作りません。
4. 襟や袖口などの接写がある項目に「細部の接写」を設定します。接写があると「細部を見る」が表示されます。接写がなく、実写真がある場合は「写真を拡大」でその写真を確認できます。
5. 必要なら「写真内のポイントを表示」をオンにし、横・縦位置を設定します。位置は大きい共通写真を基準に確認します。スマートフォン専用写真が異なる場合、誤った部位を指さないようスマホではポイントを隠します。「細部を見る」のボタンからは接写を開けます。動画上にはポイントを出しません。
6. 公開状態を管理している場合は、掲載する項目を「アクティブ」にします。
7. 商品編集画面の **「TA VIE｜写真の切り替え」** で、この商品の項目を最大8件、表示したい順に選びます。
8. PC・スマートフォンのプレビューで、切替、接写、閉じる操作、ポイント位置を確認します。

所有商品が現在の商品IDと違う項目、選択名が空の項目、画像も有効な動画もない項目は表示されません。商品専用の有効な項目が1件もない場合は、その商品の通常の実画像へ戻ります。別の商品に属する写真や原稿を補完に使いません。

## 詳しい商品特集を追加する

理由、素材、生活場面、寸法、着用感、お手入れは、任意の既存構造 **`product.metafields.ta_vie.feature`** へ登録します。[既存の定義・商品別登録手順](../product-content-model.md)を確認してください。

親の `owner_product` と、細部・生活場面・寸法の子の `owner_product` は、表示する正式商品と一致させます。商品Aの親や子を商品Bの説明へ割り当てると、所有商品が一致しないため公開画面には出ません。内容を別の商品へ流用するときも専用エントリーを作ります。

商品の実際の説明文は「商品」で編集します。特集の見出し・共通レイアウト・章の並び順はテーマエディタで編集します。同じテンプレート内の共通設定は全対象商品に反映されるため、商品独自の事実を共通セクション設定へ入力しません。

## 商品詳細の構成と、他の3着への案内

商品テンプレートの **「TA VIE 一着の特集」** で、特集の見出し、目次の表示、章の並び順、余白、配色を編集します。「写真と細部を操作する」ブロックが商品の写真切替に対応します。商品説明、作った理由、素材、家で過ごす姿、サイズ、お手入れ、製造背景、購入欄へ戻るブロックは、ドラッグで並び替え、必要に応じて無効にできます。未設定の本文・写真・寸法は公開画面で空の章にしません。

通常の商品セクションの **「TA VIEの文字組みと購入欄を使う」** は、今回の日本語の文字組みと購入欄の余白を有効にする設定です。購入機能そのものはBroadcastの標準フォームを使います。

**「写真付きの商品ナビを表示」** をオンにし、**「紹介する一着 1〜4」** に正式な4着を指定します。未選択の枠は **「紹介する商品のコレクション」** から重複を除いて選び、コレクション未選択なら全商品を使います。閲覧中の商品には「今見ている一着」と表示し、商品一覧やホームの同じ商品の特集へ戻れるリンクも用意します。

ホームの4ブロックと商品詳細の4つの選択欄は、それぞれのレイアウト設定です。管理画面の自動同期ではないため、正式な4着と順番を確定したら両方で同じ対象を選択してください。商品ごとの写真と説明は共通の `ta_vie.views` を読み込み、ホームと商品詳細で同じ商品専用データを利用します。

## メニュー・言語・SNS

**「テーマ設定 → TA VIE｜ページへのリンク」** で **「メニューにブログ・FAQを表示」** をオンにし、**「ブログのリンク先」** と **「FAQページ」** に実際の内容を選択します。任意のリンク先URLを入力した場合はそのURLを優先するため、正式なリンク先を開いて確認してください。既存メニューに同じ行き先がある場合は重複追加を抑えます。

ヘッダー・スマートフォンのメニューは、Shopify管理画面の `main-menu` と対応するテーマ設定を確認します。既存のページやブログがある場合はそれを使用し、テーマファイルの追加だけでページ・記事が作成されたと判断しません。FAQテンプレートは実際のFAQページのタイトルと本文を表示し、旧デモの送料・返品条件などは初期状態で無効にしています。ページ本文は管理画面で編集してください。

InstagramなどのURLはテーマ設定のSNS欄へ登録します。言語選択にはShopifyで公開している言語を利用します。英語やほかの言語を表示するには、言語・翻訳・Marketsの公開先も確認してください。

## カートの原稿と配送・割引

カート内とカートページの旧デモのクーポン・送料無料表示は、設定を残したまま無効にしています。カートの文章はテーマエディタのカート関連セクションで編集します。正式な割引や送料条件を表示する場合は、Shopify管理画面の割引・配送ルールと内容を一致させてください。テーマの文章だけでは、実際の割引コードや送料設定は作成されません。

## 公開前に確認する

4着をそれぞれ開き、写真・短文・接写・商品名・価格が正しいことを確認します。商品Aの項目を更新して、商品Bが変わらないことも確認します。PCとスマートフォンで切替、スワイプ、細部を開く・閉じる、商品間の移動、色・サイズ選択、在庫表示、カート追加を試してください。

キーボードのTabと矢印、Escape、フォーカスの戻り先、動きを減らす設定も確認します。Shopifyの実在庫・実カート・配送・決済、テーマエディタの保存を伴う確認は、実ストアの未公開テーマで行います。
