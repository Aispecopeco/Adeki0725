# TA VIE｜4着の写真・情報と、使う操作

現時点で正式な4商品は特定できていません。商品名・URL・素材・色を仮に決めず、ホームで選ぶ正式商品を「第1着〜第4着」に割り当ててから、下表を一着ずつ埋めてください。4着すべてに同じ写真を流用する必要はありません。実物の写真がある項目だけを掲載します。

公開ストアはパスワード画面で、商品一覧APIはHTTP 401でした。テーマZIPには服の実画像本体、商品の登録データ、寸法などの管理データは含まれていません。以前の白いシャツ写真の原画像は今回のクラウド環境で確認できず、3D試作の描画画像は実物写真の代わりに使用しません。

## 写真を何のために撮るか

| 写真・動画 | 目的と構図 | 登録する場所 |
| --- | --- | --- |
| 主役の着用写真 | 服の全体像が分かる立ち姿。襟と裾を切らず、服の周囲に余白を残す。PCの左右分割とスマホの縦画面の両方で確認 | 商品ギャラリー、必要なら写真項目の `image` / `mobile_image` |
| 側面・背面 | 身幅、肩、袖、丈の形が分かる同じ姿勢・光。体のひねりだけで輪郭を変えない | 商品ギャラリーまたは専用の写真項目 |
| 生地の接写 | 布目と表面が分かる距離。柔らかい斜めの光で質感を記録し、過度な加工で光沢を増やさない | 「生地」の `image`、さらに近い写真を `detail_image` |
| 部位の接写 | 大きい写真でポイントを置く同じ襟・袖・裾などを撮る。縫い目や仕上がりが見える倍率と解像度 | `detail_image` と確認済みの `detail_body` |
| 座った状態 | 椅子やソファで、腰回り・膝・袖の動きが見える構図。服と暮らしの場面が伝わる量の背景 | 写真項目、任意の生活場面の章 |
| 朝や夜の着用場面 | 同じ商品を着た実写。生活場面の説明と写真が一致し、商品が小さく埋もれない | 任意の生活場面の章 |
| 短い着用動画 | 歩く、座る、腕を上げるなど1つの動き。実物の裾・袖・生地の動きが見える固定した構図 | 写真項目の `video`、任意の素材・生活場面の動画 |

写真は元解像度を残して管理し、テーマ側で画面幅に合わせた画像を配信します。似た写真を大量に並べるより、見せる目的が違う写真を用意してください。スマホ専用画像で構図を変えた場合、共通写真のポイント座標はスマホでは表示しません。接写の入口はボタンで利用できます。

## 最初の一着を完成させる最低限の素材

1. 正式な商品、オンラインストアで使える実商品画像、価格・色・サイズ・在庫。
2. 服の全体像が分かる主役写真と、別の形・部位が分かる実写真。
3. 商品の説明文、写真に対応する短い説明。
4. 「細部を見る」を使用するなら、対応する実物の接写。
5. サイズ選びに必要な実寸・モデルの身長と着用サイズ、確認済みのお手入れ。

4着分を揃えるときも、上の順番で各商品の準備を進めます。接写や動画がない商品では、その操作を自然に省略して写真と説明で成立させます。空白の特集や「準備中」の公開文言、実物と違う服の画像を足しません。

## 原稿に必要な根拠

素材の混率・オーガニック認証・カシミヤの使用・原産国・製造方法・機能は、仕様書や商品ラベルなどで確認します。着心地や肌触りは、実物の確認・試着の記録とブランドの表現を分けて書きます。未確認のレビュー、配送・返品条件、保証、値引きの約束は掲載しません。

指定のフランス語はブランドの考え方として扱います。商品の機能や素材の証明ではありません。商品の説明を登録する前に、ブランドの文と事実の文を見分けられるよう確認してください。
