# TA VIE｜商品を中心にしたホームの編集

冒頭の「家での時間を、あなたらしく。」から、一商品ずつ大きな写真と文章で紹介します。現在は商品未選択の2ブロックを用意しています。主力商品が決まった後や新商品を登録した後も、商品・写真・原稿を差し替えられます。

| 順序・編集場所 | セクションID | 現在の設定 |

| TA VIE｜商品を紹介 | `ta_vie_product_stories` | 見出しH1、白背景、上余白56px・下余白72px。商品ブロック2つ、最大6つ。価格と最後の全商品リンクはオン。 |

## 商品と原稿を選ぶ

1. 未公開テーマの「TA VIE｜商品を紹介 → 商品を紹介」ブロックを開き、「紹介する商品」で正式な商品を選びます。商品名・価格・詳細ページへのリンクは実商品の登録情報を使います。並び順はブロックの移動で変更します。追加する場合は同じブロックを使い、最大6つまで設定できます。
2. 「商品の紹介文」に、その商品の使い方・着る場面と確認済みの特徴を入力します。入力文を優先し、空欄のままなら本文を省きます。「紹介文が空なら商品説明を使用」をオンにした場合だけ、登録済みの商品説明を使います。
3. 「メイン写真」を選択します。未選択なら商品のメイン画像を使います。「メイン写真の見せ方」は全体表示／枠いっぱい、「メイン写真の位置（PC）」は左／右を選択できます。
4. 「着用・暮らしの写真」と説明で、その商品を着て過ごす場面を追加します。「細部の写真」「細部の見出し」「細部の説明」は、生地や形など確認済みの特徴を伝える任意欄です。各写真が未設定なら、その写真部分と付随する説明は表示しません。

素材・組成・産地・認証・仕様は未確認で、個別原稿も現在空欄です。オーガニック素材やカシミヤの表記は、該当商品の正式資料と登録情報を照合してから入力してください。商品名や価格を仮に埋めたり、写真から素材を推測したりしていません。

## 写真とスマホ表示

PCは写真が全体の約60%を占める配置で、その横に説明を置き、一商品を一つの章として表示します。990px未満は写真 → 商品名・紹介文・価格 → 詳細リンクの1列です。写真位置が右のブロックでも、スマホは写真が先になります。

メイン写真の枠は4:5です。「メイン写真（スマートフォン）」と「着用・暮らしの写真（スマートフォン）」を別に選べ、750px未満で切り替えます。スマホ専用写真がなければ共通写真を使い、共通写真も商品写真もない場合はスマホ用メイン写真を全端末で使います。着用写真も共通未設定ならスマホ用を全端末で使います。着用枠はPC16:10・990px未満4:5、細部枠は1:1です。各枠で被写体の切れ方を確認してください。

実商品を未選択のブロックは通常ストアでは表示しません。手動写真・商品写真・スマホ用写真のどれも使えない場合は、主表示を文字・価格・リンクにします。設定した着用・細部写真は表示します。編集画面だけに商品選択・写真登録の案内を出し、未選択の商品写真や価格を補いません。セクションの導入文は商品選択前も表示します。最後の全商品リンクは実商品を1件以上紹介した場合だけ表示します。

必要な写真は、服全体が分かるメイン写真、家で着て過ごす写真、生地・襟・袖・縫い目等の寄り、スマホ向けの縦位置写真です。正式商品の写真と使用権利・商品との対応を確認して選択してください。今回、新しい写真は作成していません。

## 読みものと保持した設定

読みものはセクションの `Blog` が最優先です。未選択で「未選択時に共通ブログ設定を使う」がオンなら共通ブログ、その次に実在する `news` を候補にします。選択済みの無効・空ブログは別のブログへ置き換えません。記事欄の選択は共通ナビゲーションへ自動共有せず、任意URLも記事選択を変更しません。[ブログ・FAQの設定](navigation.md)を参照してください。

ホームJSONは22セクションを保持し、表示設定は商品紹介と読みものの2つです。元19セクションのID・設定・ブロックツリー・相対順序・参照を保持してすべて非表示にしています。以前の2×2商品グリッドも設定を残して非表示です。

全ページの書体「細めのゴシック」、ホーム専用の「Broadcastの設定を使う」、上部リンク・SNS・言語、ホーム末尾ボタン、フッター設定は前回から保持しています。新商品紹介欄には専用の画像比率・余白・文字サイズを設定しています。ヘッダーロゴ180／140px、フッターロゴ480／240pxと既存参照2件、メール欄のみの登録フォームも保持しています。正式SNS URLは空欄です。

保存後は同じ未公開テーマのPC・スマホで、写真・文章・実商品価格とリンク先を確認してください。テーマ公開、商品登録の編集、ブログ・FAQ・英語の作成と公開は行っていません。
