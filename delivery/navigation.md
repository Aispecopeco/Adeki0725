# TA VIE｜ブログ・FAQ・上部表示の設定

ブログ・FAQの共通リンクは、上部、PCメニュー、ハンバーガー、ホーム末尾、フッターで使用します。記事欄のBlog選択は独立しているため、同じブログに揃える場合は両方で選択してください。現在、正式なブログ・FAQとSNS URLは未設定です。

## 共通リンクと記事欄

| 編集場所・項目 | 現在の設定・操作 |
| --- | --- |
| テーマ設定 → TA VIE｜ページへのリンク → ブログのリンク先 | 共通リンクに使う既存ブログを選択。記事欄のBlog未選択時にも使用。 |
| ブログのリンク先URL（任意） | 入力すると共通リンク先として優先。記事欄には使わない。選択ブログで十分なら空欄のまま。 |
| FAQページ | 正式な既存FAQページを選択。 |
| FAQのリンク先URL（任意） | 入力するとFAQの共通リンク先として優先。選択ページで十分なら空欄のまま。 |
| メニューにブログ・FAQを表示 | オン。PC・ハンバーガーへの追加を制御。 |
| ホームにブログ・FAQのボタンを表示 | オン。ホーム末尾の2ボタンを制御し、記事欄とは独立。 |
| ブログへのリンク名／FAQへのリンク名 | 「ブログ」／「よくあるご質問」。 |
| ホーム → 暮らしの読みもの → Blog | 記事欄の最優先選択。公開記事のある既存ブログを選択。 |
| 同セクション → 未選択時に共通ブログ設定を使う | オン。Blog未選択なら共通ブログ、それも未選択ならnewsを候補にする。 |

共通リンクは任意URLを優先し、空欄なら選択ブログ・FAQページのURLを使用します。共通ブログ未選択時の候補は実在する `news`、FAQは `faq` ページか先頭50ページ内の `faq` テンプレート候補です。入力URLの到達性は自動検査していないため、保存後にリンクを開いて確認してください。既存メニュー内に同じURL・同じ資源がある場合、追加を省きます。

行き先がない通常ストアでは未設定リンクを隠します。テーマ編集画面のホーム末尾には「ブログ（リンク先未設定）」等の無効ボタンと設定案内を表示します。上部・メニュー・フッターには未設定リンクを出しません。

記事欄は実ブログURLと公開記事を取得できる場合だけ表示し、最大3件です。記事がない通常ストアでは欄全体を隠し、編集画面に選択・公開記事の案内を出します。選択済みブログが空・無効でも別のブログへ置き換えず、デモ記事も出しません。記事欄で選んだBlogは共通リンクに自動共有されず、任意URLも記事選択を変更しません。

## 上部・SNS・言語

Header → Toolbarの「上部にブログ・FAQを表示」「スマホでも上部リンクを表示」はオンです。上部の表示はPCメニュー・ホーム末尾のチェックとは独立しています。SNS・言語・地球儀表示もオン、ハンバーガーのSNSブロックも有効です。正式SNS URLは空欄のため、現在SNSアイコンは出しません。テーマ設定のSNS欄へ確認済みのブランドURLを登録してください。

公開言語が1つなら上部に実際の言語名を表示し、複数なら標準の切替フォームを使用します。テーマの表示設定だけでは英語を追加・公開しません。Shopify管理画面の言語・Markets設定で英語の追加、翻訳、公開先を確認します。実ストアの現在の言語数は未確認です。

## フッターのメニュー

「フッター → Footer → Link list」で既存のメニューを選択します。項目のあるメニューは、その標準リンクを優先して表示し、ブログ・FAQを追加しません。

メニューが未選択・空の場合だけ、「メニュー未選択時にブログ・FAQを表示」をオンにすると共通リンクを使います。現在「ご案内」はオン、「ご利用ガイド」はオフです。メニュー項目も補助リンクもなければ、列と見出しを隠します。フッターの補助は、PCメニューとホーム末尾の表示チェックとは独立しています。

メール登録はメール欄のみの既存フォームです。別セクション「Logo」で最大幅PC480px・スマホ240pxを編集できます。既存ロゴ参照と縦横比を保持しています。

## 管理画面で残る操作

既存ブログ・FAQページを確認して共通設定を保存し、記事欄も同じブログを選択します。既存ページがなければShopify管理画面で別途作成し、公開状態を確認します。PC・スマホで上部、メニュー、ホーム末尾、フッターのリンク先を開き、FAQの送料・返品条件は正式情報と照合してください。ページ本文、メニューの管理データ、記事・言語の新規作成と公開は今回更新していません。

過去の設定保存コミット `3f7e253` は確認済みですが、現在版の実ストア表示と配色警告消失は未確認です。テーマ公開は行っていません。[検証の範囲](validation.md)を参照してください。
