# TA VIE｜ブログ・FAQへのリンク

ホーム末尾のボタン、PCのナビゲーション、ハンバーガーメニューから、実在するブログ・FAQページへ進める設定を追加しました。行き先は3か所で共通です。既存メニューに同じURLまたは同じページ／ブログがある場合、メニューへの追加は省きます。子・孫階層と複数のモバイルメニューも重複確認の対象です。

## 管理画面で行う最後の設定

すでに連携している未公開テーマを開き、「テーマ設定 → **TA VIE｜ページへのリンク**」で、ストアにある正しいブログとFAQページを選択してください。

| 編集項目 | 操作・初期値 |
| --- | --- |
| 読みもののブログ | 実在するブランド用ブログを選択。 |
| FAQページ | 実在するFAQページを選択。 |
| メニューにブログ・FAQを表示 | 初期値はオン。PCとハンバーガーメニューへの追加を制御。 |
| ホームにブログ・FAQのボタンを表示 | 初期値はオン。ホーム末尾のボタンを制御。 |
| ブログへのリンク名 | 初期値は「読みもの」。 |
| FAQへのリンク名 | 初期値は「よくあるご質問」。 |

保存後、同じ未公開テーマのPC・スマホプレビューでホームのボタンとメニューを開き、リンク先が意図したブログ・FAQか確認します。既存のメニュー項目に含まれている場合は、追加リンクが重複していないことも確認してください。

未選択時の補助動作は、ブログが「記事のある `news` ブログ」、FAQが「`faq` ページ、または先頭50件のページ内で `faq` テンプレートを使うページ」です。実在する行き先のURLを取得できたリンクだけを表示します。どちらも見つからない場合、ボタンや追加メニューは表示されません。取り違えを防ぐため、ストアの正しい資源を選択欄から指定してください。

## ページが見つからない場合

管理画面のブログ記事・ページ一覧で、既存のブログ名、FAQページ名、公開状態を確認してください。FAQの本文にデモの送料・返品条件がある場合は、正式な条件を確認してから別途修正します。この対応でFAQ本文をブランドの事実として書き換えたり、新しいページ・記事を公開したりはしていません。

テーマの表示設定からリンクを追加する方式なので、管理画面のメニュー内容そのものは変更していません。既存メニューを編集したい場合は「コンテンツ → メニュー」から別途行えます。新しいJavaScript・CSSファイルは追加せず、Broadcastの既存クラスと演出を使っています。
