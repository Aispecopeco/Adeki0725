# TA VIE｜ブログ・FAQとフッターの設定

PC・ハンバーガーメニューとフッターの補助リンクは、実在するブログ・FAQを共通設定から表示します。記事欄はセクションのBlog選択を優先するため、リンクと同じブログへ揃える場合はそのブログを選択してください。

## 記事欄と共通リンク

| 編集場所・項目 | 現在の保存設定・操作 |
| --- | --- |
| ホーム → 暮らしの読みもの → Blog | このセクションのブログを優先。公開記事のある既存ブログを選択。 |
| 同セクション → 未選択時に共通ブログ設定を使う | オン。Blog未選択なら共通ブログを使い、それも未選択ならnewsを候補にする。 |
| テーマ設定 → TA VIE｜ページへのリンク → 読みもののブログ | メニュー・フッターの補助ブログを選択。記事欄のBlog未選択時にも使用。 |
| FAQページ | 実在するFAQページを選択。 |
| メニューにブログ・FAQを表示 | 現在オン。PC・ハンバーガーへの追加を制御。 |
| ホームにブログ・FAQのボタンを表示 | 現在オフ。ホーム末尾の2ボタンだけを制御し、記事欄とは独立。 |
| ブログへのリンク名／FAQへのリンク名 | 「読みもの」／「よくあるご質問」。 |

実ブログURLと公開記事を取得できる場合だけ記事欄を表示し、実記事カードは最大3件です。公開記事がない通常ストアでは欄全体を隠し、テーマ編集画面では選択・公開記事の案内を表示します。デモ記事は出しません。選択済みブログが空・無効でも他のブログへ置き換えません。

メニュー等のリンクは実在するURLを取得できれば表示できます。共通ブログ未選択時の候補は実在する `news`、FAQは `faq` ページか先頭50ページ内の `faq` テンプレート候補です。リンク先の存在と記事の有無は別の条件です。既存メニューに同じURL・同じ資源がある場合、PC・ハンバーガーへの追加は省きます。

## フッターのメニュー

「フッター → Footer → Link list」で既存のメニューを選択します。項目のあるメニューは、その標準リンクを優先して表示し、ブログ・FAQを追加しません。

メニューが未選択・空の場合だけ、「メニュー未選択時にブログ・FAQを表示」をオンにすると共通の実在リンクを使います。現在「ご案内」はオン、「ご利用ガイド」はオフです。メニュー項目も補助リンクもなければ、列と見出しを隠します。フッターの補助は、PCメニューとホーム末尾の表示チェックとは独立しています。

メール登録は名前欄をオフにし、メール欄のみの既存フォームを使います。フッターの別セクション「Logo」で「ロゴの最大幅（PC）」480px・「ロゴの最大幅（スマホ）」240pxを編集できます。縦横比と既存ロゴ参照は維持しています。
