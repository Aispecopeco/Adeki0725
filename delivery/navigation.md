# TA VIE｜ブログ・FAQへのリンク

ホーム末尾のボタン、PCのナビゲーション、ハンバーガーメニューから、実在するブログ・FAQページへ進めます。同じブログ選択を、現在のホームの読みもの記事欄も使います。既存メニューに同じURLまたは同じページ／ブログがある場合、メニューへの追加は省きます。子・孫階層と複数のモバイルメニューも重複確認の対象です。

## 管理画面で行う最後の設定

すでに連携している未公開テーマを開き、「テーマ設定 → **TA VIE｜ページへのリンク**」で、ストアにある正しいブログとFAQページを選択してください。

| 編集項目 | 操作・初期値 |
| --- | --- |
| 読みもののブログ | 実在するブランド用ブログを選択。ホームの記事欄とブログへのリンクで共用。 |
| FAQページ | 実在するFAQページを選択。 |
| メニューにブログ・FAQを表示 | 初期値はオン。PCとハンバーガーメニューへの追加を制御。 |
| ホームにブログ・FAQのボタンを表示 | 初期値はオン。ホーム末尾のボタンだけを制御。記事欄の表示とは独立。 |
| ブログへのリンク名 | 初期値は「読みもの」。 |
| FAQへのリンク名 | 初期値は「よくあるご質問」。 |

ホームの「TA VIE｜暮らしの読みもの」で「TA VIEのブログ設定を使う」がオンになっていることも確認します。初期値はオンで、公開記事がある場合だけ標準カードを最大3件表示します。見出し・説明文・一覧リンク名はこのセクションの編集項目から変更できます。

保存後、同じ未公開テーマのPC・スマホプレビューで記事カード・ホーム末尾のボタン・メニューを開き、行き先が意図したブログ・FAQか確認します。既存のメニュー項目に含まれている場合は、追加リンクが重複していないことも確認してください。

未選択時の補助動作は、ブログが「公開記事のある `news` ブログ」、FAQが「`faq` ページ、または先頭50件のページ内で `faq` テンプレートを使うページ」です。選択済みのブログが無効・空でも別のブログへ置き換えません。実在する行き先のURLを取得できたリンクだけを表示します。公開記事を取得できない場合、記事欄は見出し・説明・カードを含めて非表示にし、デモ記事を出しません。選択したブログURLが実在すれば、記事欄が非表示でもメニュー等のリンクは表示できます。

「メニューにブログ・FAQを表示」はPC・ハンバーガー、「ホームにブログ・FAQのボタンを表示」は末尾ボタンだけに作用します。記事欄はこれらと独立して、セクションの表示状態と実記事の有無で決まります。取り違えを防ぐため、ストアの正しい資源を選択欄から指定してください。

## ページが見つからない場合

管理画面のブログ記事・ページ一覧で、既存のブログ名、FAQページ名、公開状態を確認してください。FAQの本文にデモの送料・返品条件がある場合は、正式な条件を確認してから別途修正します。この対応でFAQ本文をブランドの事実として書き換えたり、新しいページ・記事を公開したりはしていません。

テーマの表示設定からリンクを追加する方式なので、管理画面のメニュー内容そのものは変更していません。既存メニューを編集したい場合は「コンテンツ → メニュー」から別途行えます。新しいJavaScript・CSSファイルは追加せず、Broadcastの既存クラスと演出を使っています。

フッターの「Customer Care」「Resources」は元設定でメニュー未選択です。フッターの該当リンクブロックで実在するメニューを選ぶと、登録済みの項目を表示できます。
