## 編集と、追加を外す方法

1. Shopifyの「オンラインストア → テーマ → カスタマイズ」でホームを開きます。元のセクションはこれまでの場所で編集します。
2. 「TA VIE｜一着を知る」の4商品ブロックに対象商品を選び、追加部分内の順序・文章を編集します。未指定枠は公開コレクションから重複なく選びます。
3. 商品テンプレートの「TA VIE 一着の特集」で章を並べ替え、紹介する4商品を選びます。商品ごとの写真・接写・素材・寸法は[登録手順](../luxury-experience/editing-guide.md)を使います。元の商品説明は元の場所に残し、特集内での説明再掲は既定で無効です。
4. 「TA VIE｜読みものとご案内」で実在するブログ・FAQ・お問い合わせを選びます。Instagramは元のテーマ設定を使います。
5. 追加を外したい場合は、この3つの追加セクションだけを非表示または削除します。元のセクションとコードには影響しません。ホームと商品ページはそれぞれで設定します。

商品、ブログ記事、FAQページ、実物写真、商品メタフィールド定義はテーマの更新だけでは作成されません。追加部分は実データを読み込み、未設定の写真や説明に仮文言を出しません。元のBroadcast側の表示や既存の原稿は元のままで、今回の作業はその正確性を保証するものではありません。
