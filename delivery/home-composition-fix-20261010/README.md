# TA VIE｜ホーム全体の構成を復元

2026年10月10日。商品特集を追加した際、ホームの既存19セクションをすべて無効にしていました。その結果、商品以外のブランド紹介や生活の場面が表示されなくなっていました。Broadcast 8.1.1の標準セクションを再利用し、ホームを次の5章へ戻しています。

1. **ブランドの入口**：大きな見出し、紹介文、一着ごとの特集へ進むボタン。
2. **TA VIEの想い**：「家にいる自分を、大切に。」というブランド紹介。
3. **一着ごとの特集**：既存の4着の紹介、写真切替・接写・商品詳細・サイズ選択への入口。
4. **家で過ごす場面**：朝の支度、読書をする午後、一日を終える夜。
5. **読みものとご案内**：実際のブログ記事、FAQ、お問い合わせ、Instagramへの入口。

商品詳細と購入・カートの機能は維持しています。元の19セクションの設定は残し、ブランド入口・ブランド紹介・生活場面の3つを復帰しています。その他16セクションは設定を変更していません。

## Shopifyで編集する場所

「オンラインストア → テーマ」で `ta-vie-shopify-20261005` に接続しているテーマの同期状態を確認し、「カスタマイズ → ホームページ」を開きます。

| 内容 | セクション・設定 |
| --- | --- |
| 最初の大きな写真とスマホ用写真 | Slideshow (Nested) → 最初のImageブロック → Image / Mobile image |
| 最初の見出し・文章・ボタン | 同じImageブロック内のHeading / Text / Single button |
| ブランド紹介の写真と文章 | Image with text → Primary image / Secondary image、見出し・本文ブロック |
| 商品の紹介順と対象4着 | TA VIE｜一着を知る → 紹介する一着、4ブロックの並べ替え |
| 朝・午後・夜の写真と文章 | Columns → 各Imageブロック |
| 読みもの、FAQ、お問い合わせ | TA VIE｜読みものとご案内 → ブログ・ページの選択、紹介文 |
| Instagram | テーマ設定 → Social media → Instagram。既存の設定を使います |

最初の3つの標準セクションでは「TA VIEのホーム導入として表示」などの追加設定を有効にしています。写真未設定時は仮画像や空の半幅領域を出さず、文章だけで読みやすく表示します。実写真を選ぶとBroadcastの画像配置・左右分割へ戻ります。商品特集の「見出しの役割」は主見出しと重ならないよう `h2` です。入口ボタンの `#ta-vie-home-collection` と商品特集の「ページ内リンクの目印」は対応しています。

ブログとFAQはセクションで明示的に選んだ対象を優先し、未選択なら既存のテーマ設定・実在する `news` ブログや `faq` ページを使用します。テーマ設定の明示URLも引き継ぎます。記事0件ではサンプル記事を出しません。存在しないページへのボタンや空の写真枠も出しません。未設定箇所の案内はテーマエディタ内だけに表示します。

商品の独立した写真切替・細部・素材・サイズなどは、従来の[商品別の編集手順](../luxury-experience/editing-guide.md)を引き続き使用してください。ブログ記事、FAQページ、商品の実物写真は、テーマコードの更新だけでは新規作成されません。

## 検証と反映の範囲

PC 1440px・スマートフォン390px/360pxの16ケースで5章の順序、単独CTA、主見出しが1つであること、画像未設定・商品未登録・ブログ未設定・記事0件の表示、写真切替・接写・商品間移動、キーボード操作、JavaScriptなしの表示を確認しました。商品特集の追従ナビは、その章の範囲に収まり、生活場面や読みものへ移った後は画面に残りません。単体HTMLもPC・スマートフォンの2ケースで、最初の文書取得後の追加通信なしで写真切替・接写・商品間移動が動作することを確認しました。管理された検証ブラウザーは `file://` を制限するため、直接ファイルを開く検証は行わず、許可されたローカルHTTPで確認しています。

静的な[構造・配色の確認](structure-validation.json)では13個の配色IDが現在設定と全プリセットで一致し、設定・章の構成にエラーはありません。[Shopify Theme Check](theme-check-comparison.json)は元テーマ由来の4エラー・337警告が残るため終了コード1です。新しい指摘はありません。既存の `section-double.liquid` の複雑度警告は、未設定画像の処理追加で141から152へ増えています。商品購入処理の変更は今回行っていません。

リポジトリ直下の448テーマファイルをZIPに含め、全ファイルとCRCを確認しました。元テーマの127アセットは一致しています。作業ブランチとShopify連携ブランチへ履歴を保持して反映しています。Shopify管理画面への認証がないため、Shopify側の同期完了、実商品の表示と現在の公開テーマは直接確認できていません。
